# 시내버스 정원 확장 v5 · 2026-11-08

이 폴더는 시내버스 8개 노선의 평일 계획·제조사 참고 정원·과거 자료와 v5 계산 근거를 보존합니다. 이용자용 가정·자료·출처 설명서는 `../documentation/methodology_source.md`에서 생성하며 사이트의 `methodology.html`·`methodology.md`로 제공합니다.

- 일반 참고 승객정원 50명, 마을 24명. 제조사 제원에서 운전석 제외. 실제 노선별 투입 차종·차량 등록정원은 미확인입니다.
- 5511·5513·5516·관악02-1·02-2는 보존 전체 정류장, 5515·5528·6515는 정문→서울대입구역 5정류장 구간입니다.
- 첫차·막차·배차간격은 공식 공개 응답의 **평일 구분**을 사용합니다. 균일 배차로 재구성한 시각이며 정확한 회차표·정류장별 통과시각 실측이 아닙니다.
- 20개 과거 평일의 시간당 구간 재차합은 비교 맥락입니다. 차량 한 대의 인원이나 여석으로 변환하지 않고 대기열·배경 승객 입력에 더하지 않습니다.
- 저장된 제공기관 구간속도는 이동시간 보정에 사용합니다. 시간대별 실측 완주시간 평균이 아닙니다.
- 외부 배경 승객은 미포함입니다. 시내 줄에서도 직접 도보·준비된 동일 승차지 호환 후보를 재판단합니다.

`sources/`는 원문·공개 응답·수집 메타데이터입니다. `prepared.json.gz`는 v4 입자와 보행망을 재사용한 v5 입력이며 변경된 입력 해시는 조용히 덮어쓰지 않습니다. `audit-배차-요일.json.gz`는 전체 가중 이동·대기 기록, `run-*.json`은 개별 실행 영수증, `independent_verification.json`은 10개 조건의 독립 검산, `results_summary.json`은 수업 종료 집단의 요약입니다. `revisions/`에는 초기·부분·비최적화 구현과 완료된 중간 파일을 보존했습니다. 이 폴더는 웹 배포에 포함하지 않습니다.

재계산은 시뮬레이션 폴더에서 순차적으로 `python city_capacity_model.py`를 실행합니다. 이후 `python verify_city.py`로 10개 조건을 확인하고 그래프 자료·요약을 생성합니다. 병렬 실행 시에는 개별 `--day 월 --scenario peak`처럼 조건을 나누고, 공통 파일을 한 번 만든 뒤 나머지 작업에 `--skip-common`을 붙입니다. 입력·결과를 바꾸기 전 기존 파일을 별도 버전으로 보존해야 합니다.

화면 확인은 `python build_city_viewer.py`, 문서 생성은 `python documentation/build_methodology.py`입니다. `public/city.html`에서 검증한 뒤 `public/index.html`에 같은 진입 화면을 반영합니다. 정적 배포는 `deployment/prepare_static.py`의 허용 파일 목록만 사용합니다. 인증정보·원본 수강파일·전체 감사 기록은 공개하지 않습니다.

구현 검산 PASS는 현실의 대기시간·혼잡 예측 정확도 검증을 뜻하지 않습니다. 이전 v3·v4는 그대로 보존하며, v5와의 차이를 정원 한 요인의 인과 효과로 해석하지 않습니다.
