# 혼잡에 따른 경로 변경 검토 (2026-11-10)

선택한 후보는 `initial_refit_H`입니다. 기존 공개 v7 수요의 ID, 건물, 목적지, 가중치, 출발시각과 공급·속도를 유지했습니다. 변경 횟수에는 상한·예산·소진이 없으며, 두 번째 변경부터 기본 성향이 0.30배씩 감소합니다. 본인의 만차 경험·긴 대기·혼잡은 별도의 재판단 성향을 높입니다. 20분에 강제로 이탈시키거나 줄을 40명으로 자르지 않습니다.

월~금 × 기준/피크 10개 경우에서 보존·FIFO·정원·차량 시각·연속 대기·모든 99개 대기열을 별도로 재검산했습니다. `initial_refit_H/independent_verification.json`과 `all_stops_waits.csv`가 근거입니다. 20분 초과 연속 대기는 이 10개 계산에서 0이며, 이후의 모든 수요·난수·조건에 대한 보장이 아닙니다. 두 장소 약 40명은 실측 상한이 아닌 사용자 기억 참고값입니다.

같은 분내 시각 미상 관측 3건으로 기존 정문 초기 경로 계수를 0.75에서 0.70으로 소폭 재적합했습니다. 새 수요를 추가하거나 삭제하지 않았습니다. 동일 관측을 재사용한 후보 선택이며 **독립 경험적 정확도 검증이 아닙니다**. 사례별 오차는 개선·악화가 섞여 있고 전후 합계는 13.2791→12.6766명 상당입니다. 선택 규칙도 파일에 기록했습니다.
