# 가정·자료·출처 설명서

**2026-11-08 시내버스 확장판 · 시뮬레이션 v5 / 경로 추천은 별도 모형**

이 문서는 [시뮬레이션 지도](./)와 [개인별 경로 추천](https://snu-route-lab.vercel.app/)을 함께 이해하기 위한 설명서입니다. 저장된 입력·코드·검증 기록을 대조해 작성했으며, 웹 배포일과 자료의 기준일을 구분합니다. 2026-11-08에 배포했다고 해서 모든 입력이 그날 조사된 자료라는 뜻은 아닙니다.

## 1. 무엇을 계산한 것인가

**수업 시간표와 수강신청인원을 출발량의 기반으로 사용했습니다. 개인별 실제 목적지와 귀가를 추적한 자료는 아닙니다.** 강좌 종료 사건에 이동 비율·목적지 비중·보행·배차·정원·경로 선택 가정을 적용해 이동과 대기열을 계산했습니다.

| 구분 | 확보하거나 구현한 내용 | 해석할 때의 경계 |
|---|---|---|
| 확인한 자료 | 강좌검색 보존본의 수업 요일·종료시각·강의실·수강신청인원, 공식 운행계획, 지도와 노선 정보 | 수강신청인원은 출석·귀가·버스 이용 인원이 아님 |
| 사용자 채택 조건 | 대형 셔틀 정원 60명, 교내 최고 40km/h, 교외 목표 65km/h, 과거 방향 비중과 기숙사 비율의 참고 사용 | 실측값 또는 법정 제한속도로 표시하지 않음 |
| 분석자가 정한 모형 가정 | 수업 직후 이동 50%, 보행·건물 이탈 분포, 경로 변경 기준, 미래 유입 미예측 | 실제 학생 선호를 조사해 적합한 계수가 아님 |
| 계산 결과 | 가중 통행량, 승차·차내 점유, 만차 잔류, 경로 변경, 대기·총시간 | 실제 GPS, 고유 학생 수, 실측 혼잡과 구분 |

계산 흐름은 **수업 종료 → 건물 이탈 → 목적지 배정 → 보행·경로 선택 → 정원 제한 승차 → 잔류 또는 경로 변경 → 목적지 도착**입니다. 개설 학과, 실제 강의동, 학생 소속, 개인의 마지막 수업은 서로 다른 정보입니다. 윗공대 분석은 강의실이 301·302동인 출발 집단을 따로 보는 방식이며 공대 개설 과목 전체와 같지 않습니다.

## 3. 목적지와 기숙사 비율

### 과거 방향 비중

[S6 교통체계 마스터플랜 재게시 자료](#source-s6)의 과거 비중을 사용자가 요청한 참고 시나리오로 채택했습니다.

| 원자료 구분 | 판독 비중 | 모형의 교외 대표 목적지 | 교외 배분 계산 |
|---|---:|---|---|
| 봉천동권 / 서울대입구역 | 55.7% | 서울대입구역 인근 | 55.7 / 99.9 |
| 낙성대동권 / 낙성대역 | 27.2% | 낙성대역 인근 | 27.2 / 99.9 |
| 신림동권, 대학동 포함 | 17.0% | 대학동고시촌입구 인근 | 17.0 / 99.9 |

**총학생회 교통총조사의 실제 응답 비율이 아닙니다.** 학생만·하교만·대학동만의 비중도 아닙니다. 기준은 2022년 4월 평일, 신림선 개통 전으로 기록된 통행 자료입니다. 발행기관 원문 PDF는 미확보이고 재게시 텍스트를 판독했습니다. 방향별 통행량 합계 41,805와 표시 총계 41,814 사이에 9의 차이가 있습니다. 비중 합계 99.9%를 정규화해도 이 품질 문제와 모집단 차이가 해결되지는 않습니다.

### 기숙사 비율과 배분식

기숙사 비율은 `r = 5,772 / 29,613 ≈ 19.4914%`를 채택했습니다. 분자 5,772는 [생활관 현황](#source-s7)의 학부 3,122·대학원 2,650 합계입니다. 2026-11-08 공개 페이지에서도 숫자를 확인했지만 표의 통계 기준일과 정원·실거주 구분은 명시되지 않았습니다. 분모 29,613은 [2025년판 통계연보](#source-s8) 203쪽을 근거로 보존한 2025-04-01 전교 재학생 참고값입니다.

**두 값의 기준일·캠퍼스·모집단이 일치하는지 확인되지 않아 현재 관악 수강생의 실측 거주율로 해석하지 않습니다.** 학부·대학원 생활관 구성비 역시 각 학위과정 전체의 거주율과 다릅니다.

수강신청인원 `N`, 직후 이동 비율 `q=0.5`일 때 배분은 다음과 같습니다.

```text
기숙사       = N × q × r
서울대입구   = N × q × (1-r) × 55.7/99.9
낙성대       = N × q × (1-r) × 27.2/99.9
대학동 대표점 = N × q × (1-r) × 17.0/99.9
```

기숙사 대표점은 강좌 이수과정을 편의상 이용해 학사 강좌는 919동, 그 외는 900동으로 나눕니다. 실제 개인의 학위과정·거주 동을 확인한 배정이 아닙니다. `q=50%`도 개인의 마지막 수업을 관측해 구한 귀가 비율이 아닙니다.

## 5. 배차·속도·정원·만차 잔류

### 운행과 배차 시나리오

[S3 공식 운행계획](#source-s3)은 정규학기 일반 평일의 시간·간격·막차 조건을 제공합니다. 정확한 내부 회차별 출발표는 없어 동일한 예시 출발위상으로 비교합니다.

| 노선 / 시간 | 기준 조건 | 피크 최소 간격 조건 | 해석 |
|---|---:|---:|---|
| 행정관 → 서울대입구, 15~19시 | 4분 | 3분 | 공식 3~5분 범위의 중간값·하한 |
| 교내 순환, 15~19시 | 6분 | 5분 | 공식 5~7분 범위의 중간값·하한 |
| 행정관 ↔ 대학동, 주간 해당 구간 | 10분 | 10분 | 이번 비교에서 유지 |
| 호암 경유 역순환 | 20분 | 20분 | 302동 출발 09:50~17:10 범위 기준 |

다른 시간대·막차 조건은 두 시나리오에서 같습니다. 15~19시를 데이터로 자동 탐색한 것은 아닙니다. 공식 자료의 9~10월 한시 증차·시험기간 증차를 일반 평일에 상시 적용하지 않았습니다. 야간은 기존 계산의 2대 동시 출발 가정을 유지하며 각각 60명으로 처리하지만, 공표된 대수만으로 내부 동시 출발표가 확인된 것은 아닙니다. 24시 이후 심야 셔틀은 화면 시간 범위 밖입니다.

### 정원과 속도

- **대형 셔틀 60명:** 사용자 지정 가정입니다. **역순환 25명:** 공식 안내의 25인승을 구분해 사용합니다.
- 도착 후 승차 준비 20초를 마친 흐름부터 FIFO로 태웁니다. 앞 정류장에서 탄 흐름이 뒤 정류장의 자리를 차지하고, 하차 후 여석에 승차합니다. 못 탄 흐름은 다음 차량까지 남으며 그 지연이 다음 보행·환승에도 전파됩니다.
- **교내 최고 40km/h·교외 목표 65km/h:** 사용자 요청을 적용한 속도 가정입니다. 실제 속도나 법정 제한속도를 조사한 값이 아닙니다. 저장된 캠퍼스 경계와 도로 도형, 가감속 1m/s², 정류장 15초 정차를 적용합니다. 최고속도와 평균속도는 다릅니다.
- 화면의 1초/초~15분/초는 재생 배율이며 km/h 조건과 별개입니다.
- v5는 시내버스에도 정원을 적용합니다. **일반 50명·마을 24명은 제조사 제원에 따른 참고 시나리오**이며 노선별 실제 투입 차종·등록정원은 확인하지 못했습니다. [S12 제조사 제원](#source-s12)의 운전석을 제외한 승객 정원입니다.
- **외부 배경 승객은 포함하지 않았습니다.** 수업 외 승객·교직원·방문객·실차의 기존 탑승객이 차지하는 자리는 재현하지 않아 현실보다 여석이 많을 수 있습니다. 신호·정체의 일별 변동·차량 재회차·기사 근무·요금·날씨·피로는 따로 모형화하지 않았습니다.

공식 노선경로를 보존한 도로 도형과 저장된 제공기관 구간속도를 사용합니다. OSM 캠퍼스 경계가 도로변 정류장을 제외하는 경우를 보완해, 공식 정류장명으로 확인한 교내 정류장 사이의 시내버스 구간은 전체를 최고40km/h로 처리합니다. 신소재→건설환경종합연구소·윗공대·교내 기숙사 구간을 포함합니다. 이는 사용자 속도 조건의 공간 분류 가정이며 법정 제한속도 자료가 아닙니다. 정류장명 목록과 구간별 적용 표지는 보존 입력에 기록했습니다. 최초 5개 노선 속도에는 2026-11-06의 스냅샷, 추가 3개에는 2026-11-07 저장 응답이 들어 있습니다. **요일·시간대별 실측 운행시간 평균이 아닙니다.** 구간 시간은 `max(40/65km/h 가감속·정차 곡선 시간, 도로 길이 / 저장 구간속도)`입니다. 관측속도 시간에 별도 정차 15초를 다시 더하지 않으며, 더 긴 구간시간에 맞춰 차량의 위치·표시 속도를 함께 늦춥니다.

차량 ID는 모형 출발 회차의 식별자입니다. 서로 다른 ID의 수를 필요한 고유 실차 대수로 해석할 수 없으며, 최소 간격 조건의 실제 차량 배치 가능성까지 검증한 운행 최적화가 아닙니다.

## 6. 공동 대기열과 줄을 보고 경로를 바꾸는 v5

최초 집단·목적지를 유지한 채 셔틀과 시내버스 승차 준비 완료 시점·대기 중 60초마다·만차로 못 탄 뒤에 **지금부터 남은 목적지 도착시간**을 비교합니다. 이미 기다린 시간을 두 선택에 다시 더하지 않습니다.

| 재판단 요소 | 구현한 조건 | 근거의 상태 |
|---|---|---|
| 현재 경로 대기 예측 | 자기 앞 가중치, 예정 도착, 정원, 모형 내 현재 차내 점유·앞선 하차 | 모형 상태를 사용. 실제 학생이 이를 정확히 아는지 미확인 |
| 미래 유입 | 현재 이후 새로 올 학생을 예측에 넣지 않음 | 미래 줄을 미리 보고 선택하지 않음 |
| 변경 대안 | 셔틀 줄: 기존 도보·환승·정문 후보. 시내 줄: 직접 도보와 같은 승차지의 준비된 호환 노선 | 전체 정류장 간 완전 재탐색은 아님. 목적지 유지 |
| 최소 개선 | 예상 도착 120초 이상 단축 | 분석자가 정한 시나리오 값 |
| 재판단 / 유지 | 60초 간격 / 변경 후 180초 유지 | 실제 선택 행동에서 적합하지 않음 |
| 횟수 / 복귀 | 흐름당 최대 2회, 떠난 셔틀 승차지로 복귀 제외 | 과도한 왕복 변경 완화 |

### 서울대학교 정류장 5개 노선

[S4 서울시 노선 정보](#source-s4)에서 서울대학교 **ARS 21128 / ID 120000029** → 서울대입구역2번출구 **ARS 21252 / ID 120000150** 방향을 확인했습니다. 반대편 정류장 21127·21376과 구분합니다.

| 노선 | 확인한 진행 방향 | 공개 평일 간격 | 승차 → 하차 순번 |
|---|---|---:|---:|
| 5511 | 중앙대학교 | 7분 | 21 → 25 |
| 5513 | 벽산블루밍아파트 | 9분 | 9 → 13 |
| 5515 | 청림동현대아파트 | 9분 | 7 → 11 |
| 5528 | 사당역 | 12분 | 30 → 34 |
| 6515 | 양천공영차고지 | 10분 | 70 → 74 |

다섯 노선의 해당 구간 정류장 ID 순서가 같습니다. 새로 추가한 5515·5528·6515는 필요한 정문→역 구간만 넣고, 동일한 정류장 순서의 저장 도로 도형을 재사용했습니다. 모든 노선의 전 구간을 새로 모형화한 것은 아닙니다.

v5는 이 다섯 노선 중 **실제로 여석이 있는 첫 호환 차량**을 탑니다. 시내버스는 물리적 정류장 ID를 기준으로 55개의 공동 대기열을 공유하되, 같은 방향·순번으로 탈 수 있는 흐름 사이에 FIFO를 적용합니다. 다른 목적지 노선을 기다리는 흐름은 호환 승객의 승차를 막지 않습니다. 차량은 전 정류장의 탑승·하차와 점유를 이어받고, 만차 잔류 흐름은 다음 회차 또는 경로 변경을 기다립니다. 예측에는 현재 모형 대기열·차내 인원만 사용하고 미래 유입과 아직 발생하지 않은 상류 승차는 미리 넣지 않습니다.

v3·v4의 시내버스는 08:00~23:10 고정 난수 위상·무제한 정원 방식이었습니다. 이 자료는 이전 버전으로 보존했습니다. 새 v5는 공식 평일 기점 시계와 구간속도·정원·시내 줄 재판단이 함께 바뀌므로, 두 버전의 차이를 정원 하나의 인과 효과로 해석하지 않습니다.

## 7. 지도·그래프와 전후 비교의 분모

**정원·통계는 전체 가중 흐름으로 계산하고, 지도 점은 그 뒤 줄여 표시합니다.** 점 1개는 약 2명 상당의 표시 표본이며 점을 세어 실제 학생 수나 정확한 탑승 인원을 구하면 안 됩니다.

| 지표 | 분모와 의미 | 주의할 점 |
|---|---|---|
| 현재 대기량 / 빨간 만차 잔류 | 해당 승차지에서 기다리는 가중 흐름 / 그중 한 번 이상 못 탄 흐름 | 고유 실제 학생 수가 아님 |
| 지도 그래프의 평균·90백분위 대기 | 그 정류장·도착 시간대의 **탑승 완료 흐름** | 줄을 떠난 흐름과 미탑승은 별도. 전후에 분모가 달라질 수 있음 |
| 경로 변경량 | 그 승차지에서 줄을 떠난 사건의 가중치 | 한 흐름이 두 승차지에서 바꿀 수 있어 고유 인원 아님 |
| 전후 비교의 누적 대기 | 동일한 최초 집단 전체의 모든 대기 구간 합 / 그 집단 가중치 | 떠나기 전 대기·다른 버스·환승 대기를 포함. 도보만 이동은 0분 |
| 전후 비교의 총시간 | 수업 종료부터 목적지까지, **양쪽에서 전체 가중치가 완주한 동일 최초 입자** | 건물 이탈·보행·대기·차내 모두 포함. 미도착을 0으로 처리하지 않음 |
| 23:10 제한 경과시간 | 전체 집단의 도착 또는 23:10까지 경과시간 | 미도착을 포함한 제한 지표이며 완주 총시간이 아님 |

전후 비교는 최초 **수업 종료 시간대**를 고정합니다. 변경 뒤 정류장 도착 시간대로 집단을 다시 나누지 않습니다. ‘피크 최소 간격’은 배차 시나리오 이름이고 ‘15~19시 수업 종료 집단’과 구분해야 합니다.

## 9. 경로 추천 사이트와 이번 변경의 범위

이번 v5 변경은 시뮬레이션 지도에 적용했습니다. **별도 경로 추천 앱에 시내버스 정원 엔진이 자동 적용됐다는 뜻은 아닙니다.** 아래는 앞서 연결한 v0.10 계열의 보존 구현 설명이며, 추천 앱의 독립적인 변경·실시간 가동 상태는 이번 문서에서 재검증하지 않았습니다.

[경로 추천 사이트](https://snu-route-lab.vercel.app/)는 사용자가 선택한 출발지·목적지·시각에서 경로를 계산합니다. 위의 비중을 방문자 개인의 목적지로 무작위 배정하지 않습니다. 다만 v0.10의 자동 셔틀 줄 추정은 이 비중과 이동 50%를 포함한 **집단 수요 참고 모형**을 사용합니다. 아래는 v0.10 계열 코드·설명서 대조 기준입니다.

| 항목 | 시뮬레이션 지도 | 개인별 경로 추천 |
|---|---|---|
| 이동 대상 | 강좌 기반 가중 집단 | 사용자가 선택한 출발·목적지 |
| 차량 도착 | 저장된 예시 운행 시계 | 유효한 관측 도착예정 우선, 없으면 시간표·배차 추정으로 표시 |
| 차내시간 | 최고 40/65km/h 속도 곡선 | 같은 차량 ETA 차이, 통과시간 이력·구간 소통속도·저장 속도 등 근거에 따른 계산. 40/65를 일괄 적용하지 않음 |
| 정문 공동노선 | 고정 난수 위상에서 먼저 오는 차량 | 탑승 가능한 관측 첫 차 우선. 미관측이면 노선별 독립 균등 잔여대기 가정으로 첫 차 대기 추정 |
| 대기줄·여석 | 모형 내 상태 | 수업 기반 유입·차량 정원으로 자동 추정. 실제 줄·여석을 자동 측정한 값은 아니며 신선한 직접 입력을 선택 보정으로 사용 |
| 재판단 | 모형 시간에 따라 재생 | 정류장 도착을 선택한 뒤 화면이 보이는 대기 상태에서 선택적으로 60초 재계산 |

### v0.10의 수동 입력 없는 자동 줄 추정

최초 검색부터 행정관·순환·역순환의 43개 노선별 정차 위치에서 자동 줄·대기를 추정합니다. 보존된 수업 종료·보행·환승 도착 모형의 **10회 평균 조건부 유입**을 3,385개 요일·정류소·5분 셀로 집계하고, 이를 15초 균등 도착으로 복원합니다. 하차 방향 비중은 대표 반복의 경로 구성을 사용합니다. 앞 정류장 승차와 다음 정류장 하차가 같은 차량 여석에 미치는 영향을 반영하며, 검색 시점의 줄과 보행 후 도착 시점의 줄을 구분합니다. 실제 줄·승차·여석의 측정값은 아닙니다.

과거 요일·시간별 상대 수요와 같은 방향·구간의 신선한 차량 혼잡 관측을 각각 계수 0.25로 유입 배율에 반영하고, 배율을 0.75~1.25로 제한합니다. **계수와 배율 한계는 미보정 운영 가정**이며 통계적으로 추정한 상관계수나 입증된 정확도 개선값이 아닙니다. 동일 차량의 반복 관측은 한 번 사용하며 다른 구간 또는 600초가 지난 값은 제외합니다. 90초 이후에는 관측 영향이 줄어들고, 미래 지정 검색에 현재 혼잡 관측을 쓰지 않습니다.

기준 대기는 60명·역순환 25명 정원, 미관측 배경 점유 10% 유보, 8개 배차 위상의 평균입니다. 수요 75~125%·배경 점유 0~20%의 24가지 조건에서 줄·대기 범위를 함께 표시합니다. **통계적 신뢰구간이 아닌 가정 변화 범위**입니다. 일부 기준 위상에서 막차 전에 탈 수 없으면 탑승한 위상만 평균내어 ETA를 만들지 않습니다. 추정 줄이 0이어도 실제 다른 승객이 없다는 뜻은 아닙니다. 이 집계·배차 방식은 지도의 대표 반복 1개 재생과 구분합니다.

자동 대기는 총시간에 한 번만 더하며 기존 시간대 평균 추가 대기를 중복 가산하지 않습니다. 기존 수집 스냅샷을 재사용하고 새 API 호출·예약 작업·저장 쓰기를 추가하지 않습니다. 휴강, 실제 줄 이탈·집단 경로 재선택, 시내버스 지연에서 전파되는 환승 지연, 실제 배경 승객은 아직 관측·모형화가 제한됩니다.

### 선택 입력과 대기 중 재판단

직접 입력한 줄·다음 차 여석·만차는 자동 추정의 선택 보정이며, 최초 차량 또는 고정 출발기회에 연결합니다. 해당 기회가 지나거나 첫 차량이 바뀌거나 90초가 경과하면 무효화하고, 다음 차량에 만차 표시나 오래된 줄 인원을 재사용하지 않습니다. 신선한 여석 자료가 제공되면 그 값을 우선하지만, 직접 입력에 따른 후속 여석을 모르면 60명·역순환 25명의 정원 상한을 쓰는 낙관적인 조건입니다. 후속 실제 여석과 유입은 미확인입니다.

추천 변경은 120초 개선·180초 유지·최대 2회의 가정을 표시하고, 수락 후 이동 중 자동 비교를 멈춰 위치 갱신 또는 다음 정류장 도착 선택을 요구합니다. 이미 기다린 시간과 완료한 승차 준비시간을 다시 더하지 않습니다.

**전체 평균 대기·총시간 감소를 개인 ETA에서 일괄 차감하지 않습니다.** 과거 시간당 재차인원 합계도 개별 차량 혼잡등급·탑승 실패 확률·지연 분으로 직접 바꾸지 않습니다. 과거 수요는 수요 참고, 구간속도는 차내시간, 관측 혼잡은 해당 차량 근거로 구분합니다. 시뮬레이션 사이트를 열어도 교통 API를 호출하거나 새 시뮬레이션을 실행하지 않습니다.

- 노선별 실제 투입 시내버스 차종·차량별 등록정원·정확한 회차별 시간표는 미확보입니다. 참고 정원·공식 평일 간격으로 계산한 조건부 시나리오입니다.
- 현재 셔틀 계약서·세부 사업내역서·차량별 내부 배차·기사 근무표는 이 모형의 확정 운행 제약이나 현실 검증 근거로 사용하지 않았습니다.
- 실제 정류장 도착량·차량별 승하차·차내 점유·탑승 실패·대기시간을 같은 날짜·시각·노선·방향으로 연결한 검증은 미완료입니다. 월간 시내버스 승차 합계나 인터뷰를 실제 셔틀 줄로 바꾸지 않았습니다.
- 2026년 7월 공개 편람의 수강인원 0 스냅샷은 현재 이동량 가중치로 사용하지 않았습니다.
- 요금·기상·피로·배경 승객·도로 정체·실제 차량 회전·정확한 첫차·막차 통과시각과 목적지 비중 변화의 현실 적합성은 추가 조사 대상입니다.

현실과 비교하려면 수업 종료, 정류장 유입, 승차, 차내 점유, 대기열을 구분해 같은 조건의 관측과 대조해야 합니다. 코드 검사·공개 배포 성공을 실제 혼잡 예측의 검증으로 해석하지 않습니다.

## 12. 버전·근거 확인과 팀 공유

2026-11-07 v4에서 줄 관찰 후 경로 변경과 정문 5개 노선 공동 이용을 추가했고, 같은 날 전체 여정 기록으로 전후 비교를 재집계했습니다. 2026-11-08에는 기존 v3·v4 결과를 Vercel 정적 사이트로 배포하고, 두 사이트를 연결하는 설명서를 작성했습니다. 이어 v5에서 시내 8개 노선 차량·정원·공동 대기열·평일 운행 시계·저장 구간속도와 과거 구간 자료 비교를 추가하고 10개 조건을 다시 계산했습니다. 기존 v3·v4 데이터와 원문, 이전 설명서는 보존했습니다.
