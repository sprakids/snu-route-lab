정원과 속도

  • 대형 셔틀 60명: 사용자 지정 가정입니다. 역순환 25명: 공식 안내의 25인승을 구분해 사용합니다.
  • 도착 후 승차 준비 20초를 마친 흐름부터 FIFO로 태웁니다. 앞 정류장에서 탄 흐름이 뒤 정류장의 자리를 차지하고, 하차 후 여석에 승차합니다. 못 탄 흐름은 다음 차량까지 남으며 그 지연이 다음 보행·환승에도 전파됩니다.
  • 교내 최고 40km/h·교외 목표 65km/h: 사용자 요청을 적용한 속도 가정입니다. 실제 속도나 법정 제한속도를 조사한 값이 아닙니다. 저장된 캠퍼스 경계와 도로 도형, 가감속 1m/s², 정류장 15초 정차를 적용합니다. 최고속도와 평균속도는 다릅니다.
  • 화면의 1초/초~15분/초는 재생 배율이며 km/h 조건과 별개입니다.
  • v5는 시내버스에도 정원을 적용합니다. 일반 50명·마을 24명은 제조사 제원에 따른 참고 시나리오이며 노선별 실제 투입 차종·등록정원은 확인하지 못했습니다. S12 제조사 제원의 운전석을 제외한 승객 정원입니다.
  • 외부 배경 승객은 포함하지 않았습니다. 수업 외 승객·교직원·방문객·실차의 기존 탑승객이 차지하는 자리는 재현하지 않아 현실보다 여석이 많을 수 있습니다. 신호·정체의 일별 변동·차량 재회차·기사 근무·요금·날씨·피로는 따로 모형화하지 않았습니다.

정문 공동노선고정 난수 위상에서 먼저 오는 차량탑승 가능한 관측 첫 차 우선. 미관측이면 노선별 독립 균등 잔여대기 가정으로 첫 차 대기 추정
대기줄·여석모형 내 상태수업 기반 유입·차량 정원으로 자동 추정. 실제 줄·여석을 자동 측정한 값은 아니며 신선한 직접 입력을 선택 보정으로 사용
재판단모형 시간에 따라 재생정류장 도착을 선택한 뒤 화면이 보이는 대기 상태에서 선택적으로 60초 재계산

v0.10의 수동 입력 없는 자동 줄 추정

최초 검색부터 행정관·순환·역순환의 43개 노선별 정차 위치에서 자동 줄·대기를 추정합니다. 보존된 수업 종료·보행·환승 도착 모형의 10회 평균 조건부 유입을 3,385개 요일·정류소·5분 셀로 집계하고, 이를 15초 균등 도착으로 복원합니다. 하차 방향 비중은 대표 반복의 경로 구성을 사용합니다. 앞 정류장 승차와 다음 정류장 하차가 같은 차량 여석에 미치는 영향을 반영하며, 검색 시점의 줄과 보행 후 도착 시점의 줄을 구분합니다. 실제 줄·승차·여석의 측정값은 아닙니다.

과거 요일·시간별 상대 수요와 같은 방향·구간의 신선한 차량 혼잡 관측을 각각 계수 0.25로 유입 배율에 반영하고, 배율을 0.75~1.25로 제한합니다. 계수와 배율 한계는 미보정 운영 가정이며 통계적으로 추정한 상관계수나 입증된 정확도 개선값이 아닙니다. 동일 차량의 반복 관측은 한 번 사용하며 다른 구간 또는 600초가 지난 값은 제외합니다. 90초 이후에는 관측 영향이 줄어들고, 미래 지정 검색에 현재 혼잡 관측을 쓰지 않습니다.

기준 대기는 60명·역순환 25명 정원, 미관측 배경 점유 10% 유보, 8개 배차 위상의 평균입니다. 수요 75~125%·배경 점유 0~20%의 24가지 조건에서 줄·대기 범위를 함께 표시합니다. 통계적 신뢰구간이 아닌 가정 변화 범위입니다. 일부 기준 위상에서 막차 전에 탈 수 없으면 탑승한 위상만 평균내어 ETA를 만들지 않습니다. 추정 줄이 0이어도 실제 다른 승객이 없다는 뜻은 아닙니다. 이 집계·배차 방식은 지도의 대표 반복 1개 재생과 구분합니다.

자동 대기는 총시간에 한 번만 더하며 기존 시간대 평균 추가 대기를 중복 가산하지 않습니다. 기존 수집 스냅샷을 재사용하고 새 API 호출·예약 작업·저장 쓰기를 추가하지 않습니다. 휴강, 실제 줄 이탈·집단 경로 재선택, 시내버스 지연에서 전파되는 환승 지연, 실제 배경 승객은 아직 관측·모형화가 제한됩니다.

선택 입력과 대기 중 재판단

직접 입력한 줄·다음 차 여석·만차는 자동 추정의 선택 보정이며, 최초 차량 또는 고정 출발기회에 연결합니다. 해당 기회가 지나거나 첫 차량이 바뀌거나 90초가 경과하면 무효화하고, 다음 차량에 만차 표시나 오래된 줄 인원을 재사용하지 않습니다. 신선한 여석 자료가 제공되면 그 값을 우선하지만, 직접 입력에 따른 후속 여석을 모르면 60명·역순환 25명의 정원 상한을 쓰는 낙관적인 조건입니다. 후속 실제 여석과 유입은 미확인입니다.

추천 변경은 120초 개선·180초 유지·최대 2회의 가정을 표시하고, 수락 후 이동 중 자동 비교를 멈춰 위치 갱신 또는 다음 정류장 도착 선택을 요구합니다. 이미 기다린 시간과 완료한 승차 준비시간을 다시 더하지 않습니다.

전체 평균 대기·총시간 감소를 개인 ETA에서 일괄 차감하지 않습니다. 과거 시간당 재차인원 합계도 개별 차량 혼잡등급·탑승 실패 확률·지연 분으로 직접 바꾸지 않습니다. 과거 수요는 수요 참고, 구간속도는 차내시간, 관측 혼잡은 해당 차량 근거로 구분합니다. 시뮬레이션 사이트를 열어도 교통 API를 호출하거나 새 시뮬레이션을 실행하지 않습니다.

출처: 서울교통 빅데이터 플랫폼 TAIMS의 보존 구간 재차인원 자료. 2026-09-07~18·10-19~30의 평일 20일입니다. tdata_calibration_2026-11-07/collected/날짜/target_routes.json, route_expansion_2026-11-07/cached_history_new_routes.json을 재사용했으며 인증 API를 새로 호출하지 않았습니다. 지도에서 같은 노선·구간·방향·요일·시간대의 시간당 재차인원 합계의 날짜 평균을 별도 표시합니다. 보존 20평일·8개 노선·24시간의 구간 셀231,360개 중 재차합은183,397개가 있고47,963개는 결측입니다. 평균·최대·운행횟수는 각각231,360개 모두 결측이므로 실차 한 대의 점유·여석·차량별 탑승 실패 확률로 환산하지 않았습니다. 결측을0명으로 바꾸지 않습니다. 이 합계는 배경 승객이나 대기열 입력에 더하지 않습니다.

11. 아직 확보·검증하지 못한 범위

  • 총학생회 교통총조사의 실제 응답·방향별 결과표는 이 모형 입력으로 확보하지 못했습니다. 설문 문항을 확인한 것과 결과를 확보한 것은 다릅니다.
  • 개인별 실제 주소·목적지·수강명단 연결·출석·오늘의 마지막 수업·GPS는 확보하지 못했습니다.
  • 노선별 실제 투입 시내버스 차종·차량별 등록정원·정확한 회차별 시간표는 미확보입니다. 참고 정원·공식 평일 간격으로 계산한 조건부 시나리오입니다.
  • 현재 셔틀 계약서·세부 사업내역서·차량별 내부 배차·기사 근무표는 이 모형의 확정 운행 제약이나 현실 검증 근거로 사용하지 않았습니다.
  • 실제 정류장 도착량·차량별 승하차·차내 점유·탑승 실패·대기시간을 같은 날짜·시각·노선·방향으로 연결한 검증은 미완료입니다. 월간 시내버스 승차 합계나 인터뷰를 실제 셔틀 줄로 바꾸지 않았습니다.
  • 2026년 7월 공개 편람의 수강인원 0 스냅샷은 현재 이동량 가중치로 사용하지 않았습니다.
  • 요금·기상·피로·배경 승객·도로 정체·실제 차량 회전·정확한 첫차·막차 통과시각과 목적지 비중 변화의 현실 적합성은 추가 조사 대상입니다.

현실과 비교하려면 수업 종료, 정류장 유입, 승차, 차내 점유, 대기열을 구분해 같은 조건의 관측과 대조해야 합니다. 코드 검사·공개 배포 성공을 실제 혼잡 예측의 검증으로 해석하지 않습니다.

12. 버전·근거 확인과 팀 공유

2026-11-07 v4에서 줄 관찰 후 경로 변경과 정문 5개 노선 공동 이용을 추가했고, 같은 날 전체 여정 기록으로 전후 비교를 재집계했습니다. 2026-11-08에는 기존 v3·v4 결과를 Vercel 정적 사이트로 배포하고, 두 사이트를 연결하는 설명서를 작성했습니다. 이어 v5에서 시내 8개 노선 차량·정원·공동 대기열·평일 운행 시계·저장 구간속도와 과거 구간 자료 비교를 추가하고 10개 조건을 다시 계산했습니다. 기존 v3·v4 데이터와 원문, 이전 설명서는 보존했습니다.
