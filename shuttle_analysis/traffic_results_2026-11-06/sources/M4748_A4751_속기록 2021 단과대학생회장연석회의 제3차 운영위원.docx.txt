[인준안건 1] 동아리소개제 TF 예산안 인준의 건

총 : 동연에서 발제.
동연 : 동아리소개제 학생지원과 지원금이 3월 이후 들어올 예정이나, 현재 천막 및 부스 용품 대여 등을 위해서 예산이 필요한 상황입니다. 이에, 총학생회 일반회계에서 300만원을 동아리연합회에 지원하고, 이후 학생지원과 지원금이 들어오면 이를 다시 일반회계에 이체하는 방식으로 진행하고자 합니다. 이에 대해서 총운영위원회에서 인준해주시기를 요청드립니다.
 
* 이 경우 동소제 예산 300만원은 1기 결산에 포함되고, 2기 예산 수입 항목에 300만원이 추가될 예정입니다.

(예산 세부내역 안건지 확인)

총 : 첨언. 코터 당시 이렇게 코준위에서 중집 회계를 일부 사용하고 다시 환급한 적이 있음. 이렇게 되면 회계 기록상에는 동소제TF에 지급한 300만원은 1기 결산에 포함, 2기 예산 수입에 300만원이 추가되어 회기 분리돼서 기록될 것. 질의?
공대 : 예산안 수입에 400만원이라 되어있는데 뭐가 정확한건지.
동연 : 학지과 지원? 학지과는 3월에 400만원 예정. 이것만으로 부족한 금액을 300만원 받을 예정이라는 것. 
총 : 추가질의?
공대 : 여기 표 외에서 300 추가 지원 받는다는 말씀?
총 : 400 지원이 맞는데, 동연 금액이 따로 있어서 400까진 필요 없고 300 받는 것. 추가 질의? 질의 없으면 표결로. 표결 필요한 단위? 없으면 박수로 인준.

(발제내용 제12차 운영위원회 속기록 및 별첨 1. 참고)
(별첨 1. 제안 이유, 주요 내용 설명)
총 : 지난번에 심의한 결과 활동의 기준을 정하는 내용이 있었는데, 검토한 결과 규정이 너무 방대해질 것 같고, 심사라는 것 자체가 중집에서 진행된 뒤 총운위에서 결정하니 총운위에서 충분히 결정할 수 있다 판단해서 활동 기준은 반영하지 않았음. 조항번호 바뀌는 것들 반영했고, 비문도 수정함. 8조 7항 단어 정도 바꿨고, 제6조의1, 제6조의2 같은 가지번호 기입방식은 조항 번호 밀리는 것을 방지하기 위함이어서 그것도 그냥 조항번호를 미는 방식으로 바꿈. 총학생회 창고가 단위 단체에 포함되지 않는다는 문제가 있었기에 창고의 사용 권한은 중집에 있다고 바꿔서 단위 포함 문제 해결함. 전체적으로 찬반 받고 축조심의가 필요하다고 판단되면 축조심의로 진행하겠음. 질의?
공대 : 지난번에 개정한거 개정연월 표시돼야하지 않는지.
총 : 그건 수정하겠음. 신설은 표시했는데 삭제는 표시 안한듯. 이건 삭제마다 표시하는지 확인해봐야 하겠지만 반영하겠음. 질의? 별도 질의 없으면 찬반토론으로. 찬반의견? 아까 말한것처럼 전체 기준으로 하고, 조항별 논의가 필요하다고 생각되는 것만 축조심의로.
공대 : 질의. 개정안 제8조제6항 3일을 보니, 지난 속기 찾아봤는데 시간 72시간 내용 있던데.
총 : 그거 확인해봤는데, 대부분 규정이 시간이 아니라 일수로 되어있음. 초일불산입원칙이 있어서 별도의 언급이 없으면 민법상 그날 기준으로 3일 뒤 자정까지로 본다고 함. 그래서 시간은은 반영 안함.
공대 : 확인 감사. 
총 : 찬반의견? 신구조문대비표엔 포함 안돼있는데, 별표랑 별지까지 한번에. 조문이라 하긴 애매해서. 의견 있는 단위?
공대 : 시간 주시면 감사. 질의. 제7조제2항 3개월 내로 마무리는 임기 넘어가면 어떻게 되는지?
총 : 이번에도 임기 넘어갔는데 인수인계 해서 진행했는데, 임시 심사는 특이한 케이스긴 해서 임기 끝난다고 자동으로 종료된다 하기도 무리라서. 정기 자치공간심사는 8월에 진행되니 그냥 유지했고 임시 심사는 특이 케이스라 반영하기 어렵다 판단했음. 질의나 의견 있으시면 자유롭게.
공대 : 질의. 지난주 개정안 기준 부칙에 총학생회 창고규정 총운위 인준 조항 빠진 이유는?
총 : 설명 까먹음. 부칙으로 넣는것보단 제10조제4항 조문이 바뀌었는데, 창고관리규정을 제정하고 이를 바탕으로 관리 운영 한다 돼있음. 첫째론 이 규칙이 제정돼야 효력을 가진다는 것과 둘째로 총운위에서 한다는 것이 있을 것. 첫째론 이 규정 바탕으로 운영한다 돼있기 때문에 창고규정이 제정돼야 창고로 사용 가능하다 해석할 수 있다 판단해서 바꿨고 그렇게 되니 부칙에 들어가있는게 부자연스럽다는 피드백 있어 제외함. 총운위 사용규정의 경우 내부에서 사용하는 것이니 내부에서 하는 것이 맞다는 논지가 있을 수 있고 세칙 제정이니 총운위 의결을 받아야 한다는 논지가 있을 수 있음. 그런데 제정은 창고 사용하는 단위들 내부에서 하는 것이 맞다 생각해서 부칙에서 제외함.
공대 : 찬성. 개정안 취지에 공감하고 지난 12차 총운위에서 고려된 사항이 반영된 것 같아 찬성발언 남김.
총 : 또 발언할 단위? 질의도 좋고 의견도.
간호대 : 찬성. 마찬가지로 개정 취지에 공감, 명확한 기준도 생겨 판단에 용이함이 생겨 찬성함.
총 : 발언할 시간 필요한 단위? 반대의견 있는 단위? 없으면 표결로. 찬성의견만 나와서, 표결 필요하다 생각하는 단위? 없으면 박수로 인준. 기타안건으로.

[기타안건 1] 전체학생대표자회의 단위 수합 요청의 건

총 : 간단한 전달사항. 첫째로, 간호대는 대표 선발한다 했는데 전대 대의원에 신입생들이 들어오는 단위 있는지?
공대 : 있을 수 있음. 광역 때문에. 3월 확정?
총 : 3월은 해야됨. 
공대 : 그럼 없을듯.
의대 : 의예과 1학년 의결권 있음.
총 : 선발시기는?
의대 : 그건 모름.
총 : 절차가, 단위 받고 그 단위 대상으로 시간 수합받고 진행해서. 1학년 대표가 포함되면 변동이 심할 것 같아서 조사하는 것.
약대(부) : 1학년 오늘 선정돼서 들어와 있음.
수의대 : 예과 1학년 대표 들어오는데 보통 2월 말.
자연대 : 3월 초에 아마 1학년 대표 들어올 듯.
치대 : 치대도 들어올수도 있음.
총 : 그럼 일단 1학년 대표 자리 제외하고 현재 단과대별로 전학대회 대의원 보시고 재적단위 어디가 있는지, 양식 보내드릴테니 채워서 다음주 일요일까지 보내주시면 감사. 시기는 고민중인데 원활한 예산 인준이나 사업 진행에 있어선 3월 중순에 전학대회 하는게 중집 입장에선 좋은데 선거가 3월 말에 끝나는 경우도 있어서 3월 말도 좋을 것 같다는 생각. 고민중. 관련해서 양식 보내드리면 채워주시면 감사하겠음.

[기타안건 2] 전공설계지원센터 다전공 간담회 이공계 발표자 섭외 협조 요청의 건
중집장: 전설센터에서 다전공 간담회 이공계 발표자 섭외 협조를 요청함. 요청한 발표자 조건은 다음과 같음. 
1. 생명 통계 화생공을 제외한 이공계열 학생
2. 복수/부/연합/연계전공을 하고 있으며 5과목 이상 이수한 학생
3. 학교활동 (학생회 및 동아리)에 적극적으로 참여한 학생 (권장)
4. 수요일 12:30~14:00 발표 가능한 학생 (필요하다면 공결 확인증 발급)
발표 시기는 3월 29일 수요일 12:30~14:00. 발표 혜택은 발표비 7만원. 발표 내용은 본인의 다전공 이야기. 자세한 발표 내용은 추후 전달 예정.
