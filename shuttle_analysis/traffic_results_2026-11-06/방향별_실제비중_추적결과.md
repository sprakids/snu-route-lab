# 총학생회 교통총조사 결과와 과거 방향별 비중 추적

확인일: 2026-11-06 KST.

**새로 확보한 것:** 총학생회의 2023년 10~15차 총운영위원회 안건지·속기록 원본, 조사 참여 인원에 관한 기록, 과거 연구보고서 재게시본에 실린 접근 경로별 수치입니다. **총학생회 설문의 서울대입구·낙성대·대학동 응답 비율표는 확인한 자료에서 확보하지 못했습니다.** 아래 과거 통행 비중을 그 설문 결과로 표시하지 않습니다.

## 1. 방향별 수치가 나온 과거 보고서

[『서울대학교 관악캠퍼스 교통체계 마스터플랜 수립』 재게시본](https://www.scribd.com/document/881211763/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA-2025-04-24-15-06-29)의 표제·제출문에는 서울대학교 평의원회, 2022.9., 연구책임자 고승영이 표시됩니다. 확인한 수치의 위치는 본문 **29~31쪽, 표 2-7·2-8**입니다. 발행기관이 배포한 PDF는 확보하지 못했고, 웹 열람 도구에 제공된 재게시본 텍스트에서 확인했습니다.

| 보고서의 경로 분류 | 표에 적힌 통행/일 | 표에 적힌 비중 |
|---|---:|---:|
| 봉천동권 — 서울대입구역 | 23,276 | 55.7% |
| 낙성대동권 — 낙성대역 | 11,388 | 27.2% |
| 신림동권 — 대학동 포함 | 7,141 | 17.0% |
| 보고서 합계 | 41,814 | 100.0% |

표의 자료는 **2022년 4월 평일 교통카드 자료와 캠퍼스관리과 자료**이며 신림선 개통 전입니다. 수강생만의 하교 목적지 조사나 대학동 단독 비율은 아닙니다. 버스·셔틀 통행을 대상으로 하므로 학생 실인원·주거 분포와 구분합니다.

**검산상 보류점:** 경로별 인원 합은 41,805로 표의 총계보다 9 작고, 비중 합은 99.9%입니다. 또 낙성대권 셔틀 957은 다른 표의 낙성대 660과 사당 297의 합과 같아, 경로 분류를 원본과 대조해야 합니다. 재게시 텍스트의 인식 오류인지 원표의 집계 문제인지는 미확인입니다. 원문 숫자를 임의로 고치거나 합계 100%로 정규화하지 않았습니다. 이 자료는 **과거에 보고된 참고치**로 보존하며 현재 관악 수강생의 실측 분배율로 자동 적용하지 않습니다.

## 2. 총학생회 공식 원본에서 확인한 내용

일반 글 주소는 본문·첨부를 충분히 표시하지 않았습니다. [공식 총운영위원회 회의록 게시판](https://we.snu.ac.kr/category/%EC%B4%9D%EC%9A%B4%EC%98%81%EC%9C%84%EC%9B%90%ED%9A%8C-%ED%9A%8C%EC%9D%98%EB%A1%9D/)이 사용하는 **공개 열람 폼과 첨부 다운로드**를 그대로 이용해 원본을 받았습니다. 로그인·REST 우회·설문 응답 제출·댓글 작성은 하지 않았습니다. 읽기 전용 열람에도 사이트가 POST 방식을 사용하며, 요청 필드와 파일 해시는 `meeting_attachments.json`에 기록했습니다.

| 자료 | 확인한 내용 | 방향별 비율에 대한 결론 |
|---|---|---|
| [10차 회의, 2023.1.29.](https://we.snu.ac.kr/4704/) | 속기록의 중앙집행위원회 보고에 교통총조사 분석과 개선안 논의가 있음 | 분석을 실제 진행했다는 근거. 세 방향 빈도표는 미확보 |
| [11차 회의, 2023.2.5.](https://we.snu.ac.kr/4722/) | 안건지의 도서관 조사 관련 설명에서 앞선 교통총조사에 **2,500명이 참여했다고 언급** | 당시 문서에 적힌 참여 규모. 중복 제거·문항별 유효 응답 수가 검증된 수치는 아님 |
| [12차 회의, 2023.2.12.](https://we.snu.ac.kr/4729/) | 안건지·속기록의 캠퍼스관리과 면담 보고에서 2월 7일 조사 결과 공유와 노선 수요 검토를 설명 | 결과를 정책 협의에 사용했다는 직접 근거. 전체 목적지별 비율표는 미확보 |
| 13~15차 회의의 안건·속기 첨부 | 2월 19일 이후 후속 첨부까지 텍스트 검색 | 추가 방향별 집계표를 찾지 못함 |

12차 속기록은 **낙성대 방향 노선의 하차 지점**을 비교할 때 낙성대역 선호가 낙성대입구보다 높았다고 설명합니다. 이것은 낙성대역과 낙성대입구의 비교이며, 서울대입구역·낙성대역·대학동 중 낙성대 수요가 가장 크다는 근거로 사용할 수 없습니다. 본문에는 해당 비교의 비율이 제시되지 않습니다.

13차 속기 첨부의 파일명은 2021년 회의처럼 적혀 있지만, 문서 내부 표제와 날짜는 2023.2.19. 제63대 13차 회의입니다. 파일명을 바꾸지 않고 보존했습니다. 한글 파일 안의 이미지 21개도 추출해 접촉 시트로 확인했습니다. 영수증·거래 내역·봉사 포스터였으며 방향별 설문 결과 그래프는 찾지 못했습니다. 이 이미지들은 교통 근거로 사용하지 않습니다.

## 3. 추가로 추적한 공개 자료

- 총학생회 사이트에서 교통총조사·띄어쓴 명칭·교통조사·교통실태·셔틀 설문·하교셔틀·야간도서관·정기보고와 관련 회의 날짜를 검색했습니다. 검색 결과와 공식 공개 RSS도 저장했습니다.
- 2023.1.23. 분석회의, 2023.2.7. 결과 브리핑, 2023.7.19. 야간도서관 셔틀 설문 결과 정리 기록을 확인했습니다. 이 기록 자체를 응답 비율로 바꾸지 않았습니다.
- 2023년 하교셔틀 만족도조사 모집과 중간보고 영상 안내도 확인했습니다. 확인한 공지에는 세 방향 응답 비중이 없습니다.
- 2024년 7월 초·중순 활동보고도 추가 확인했으나 방향별 집계표를 확보하지 못했습니다. 따라서 모든 연도·모든 회의자료에 결과가 없다고 결론 내리지 않습니다.

## 4. 구현 프로젝트에 전달한 상태

사용자 요청으로 같은 프로젝트의 **「구현」** 채팅과 협업을 시작했습니다. 자료조사 담당은 `shuttle_analysis/collaboration/research_inputs.json`과 `RESEARCH_HANDOFF.md`를 맡고, 구현 담당의 앱·시뮬레이션 파일은 수정하지 않았습니다.

- 사용자가 구현 채팅에서 선택한 기숙사 인원 5,772명은 유지합니다. 5,772/29,613의 약 19.49%는 **사용자 선택 기준 시나리오**로 구분했습니다.
- 현재 관악 수강생의 실측 방향별 비중은 `null`로 유지합니다.
- 2022년 보고 수치는 별도의 과거 근거 항목으로 인계합니다. 원본 확인·표 검산 문제가 있어 현재 실제 비중이나 기본 배정 벡터로 자동 채택하지 않습니다.
- 수업 종료 인원 합계는 중복 없는 하교 인원이 아니며, 기숙사생도 교내 버스·셔틀을 탈 수 있다는 조건을 전달했습니다.

## 5. 정합성 확인

이번에 확보한 공식 조사 관련 수치는 문서상 참여 규모 2,500명입니다. 과거 경로 비중은 총학생회 설문 결과와 별개인 연구보고서 재게시본에 나온 수치입니다. 현재 학생 비중·특정 시간대 하교 비중·윗공대만의 비중으로 바꾸지 않았습니다. 출처별 보존 파일·표 전사·검산 상태는 `verification.json`, `historical_reported_shares.json`, `meeting_attachments.json`에 기록했습니다.
