# 저녁 윗공대 낙성대행과 관악02-1 이용

연구 R261127164440. 저녁은 17~21시, 윗공대는 300·301·302동이다. 모의 인원은 통행 가중치를 합한 명 상당이다. 출발 수요를 교통카드 승차 건수에 직접 맞추면 출발동·수단을 모르는 이용자까지 학생으로 세게 되므로, 출발자 집계와 카드 기준 승하차 집계를 각각 계산했다. [가정·자료·재현](설계.md)

## 검산

기준과 실험을 합친 요일·배차·조건 48개에서 출발자별 ID·출발 시각·가중치를 대조했다. 동시에 바꿨을 때의 목적지 배정도 목적지만 바꾼 실험과 같다. 정원 위반은 0건, 미완료는 0명 상당, 한 정류장 20분 초과 대기는 0명 상당으로, 최장 연속 대기는 20.00분이었다. 별도의 목요일 피크 무변경 실행은 직전 R의 개별 출발, 실제 승하차와 집계값을 재현했다. [운영 검산](운영검산.csv) · [현장 관측별 비교](현장관측.csv) · [수치 원본](results.json)
