개발·검증 후보에는 **R**, 실제 배포한 모델에는 **V**를 붙입니다. 기존 내부 시각 식별자와 과거 결과는 보존합니다. 이 후보는 공개 운영 V11이나 시뮬레이션 에이전트의 행동 모형을 교체하지 않습니다.

## 자료와 검증 경계

- 학습: 2026-11-10. 개발 비교: 이미 탐색한 2026-11-11.
- 코드·학습 입력·비교 규칙을 먼저 동결한 뒤 2026-11-12 한 날짜를 독립 날짜 검증에 사용합니다. 11/13~15는 열지 않습니다.
- 한 요일의 학습 자료만으로 요일별 차이를 검증했다고 주장하지 않습니다. 이 후보의 시간대별 분포는 평일 전이 추정입니다. 주말·수집시간 밖에는 전용 자료가 없으므로 기존 모형으로 돌아갑니다.
- 정류소 검출은 GPS가 정류소에서 60m 이내이고 정차 표시가 있으며 이전 제공기관 갱신과 120초 이내인 경우입니다. 제공 시각이 150초 넘게 오래된 기록은 제외합니다.
- 이것은 정확한 승차·출발시각이 아닌 **오차 범위가 있는 정류소 검출시각**입니다. 차량 검출 누락으로 관측 간격이 길어질 수 있습니다. 모든 버스를 빠짐없이 관측했다는 보장은 없습니다.
- 반복 관측과 같은 차량·회차의 여러 구간은 독립 표본·서로 다른 승객이 아닙니다. 구간별 MAE 외에 회차/정류장 묶음별 평균 오차도 확인합니다.
- 후보·기존 로컬 계산·마지막 관측 유지 모형을 같은 평가 대상에서 비교합니다. **실제 배포 서버의 동적 운행 입력까지 동일하게 복제한 비교는 아닙니다.**
- 셔틀은 현재 연속 위치 이력이 보존돼 있지 않습니다. 시내버스의 개선을 셔틀 실측 배차·실측 주행시간 검증으로 확대 해석하지 않습니다. 셔틀 시간표와 기존 대기열 모형은 별도로 유지합니다.
- 기존 계획의 28일 자료 검증과 운영 교체 승인은 여전히 필요합니다. 이번 한 날짜 검증만으로 운영 승격하지 않습니다.

## 경로 계산 연결

`candidate_runtime.py`는 기존 Planner의 `transit.continuity`, `travel` 및 정문 공동노선 비교에 연결할 수 있는 되돌릴 수 있는 어댑터입니다. 기존 파일을 고치거나 추가 외부 API 요청을 실행하지 않습니다. 노선망 해시가 다르면 연결을 거절합니다. `install_candidate`의 적용 대상과 구성요소를 명시해야 하며 반환된 `undo()`로 원복할 수 있습니다.

마지막 통과를 아는 조건부 예측에는 `transit.observed_stop_events`가 필요합니다. 각 행은 `r`, `s`, `at`, `seen`이며 정문 공동노선에는 `stop_id`도 포함합니다. **미래 도착예정 시각을 과거에 실제 통과한 시각처럼 넣으면 안 됩니다.** 이 입력이 없으면 조건 없는 관측 간격 분포를 사용합니다.

시내버스에서 줄·만차 위험으로 생기는 추가 대기는 기존 `city_boarding` 계층이 담당합니다. 이번 후보가 계산하는 다음 운행기회와 대기열 지연을 구분해 적용하고 같은 지연을 두 번 더하지 않습니다. 셔틀의 44명 정원·피크 두 대 시나리오·수요·목적지·인내시간·경로 선호계수는 변경하지 않습니다.

## 재현과 보존

- `baseline_app/`: 현재 로컬 계산 코드·필요 입력의 동결 복사본. 비밀키·환경 설정·기존 실행 DB는 복사하지 않았습니다.
- `baseline_manifest.json`: 원본 위치와 복사본 해시.
- `extract_observations.py`, `empirical_transport.py`: 저장 자료 재구성과 후보 계산.
- `build_candidate.py`: 학습과 개발 날짜 비교. 기존 산출물이 있으면 덮어쓰지 않습니다.
- `heldout_protocol.py`: `freeze` → `fetch` → `evaluate`. 동결 후 파일이 바뀌면 검증을 거절합니다.
- `artifacts/frozen_protocol.json`: 날짜, 품질 조건, 평가 규칙, 97개 파일의 해시.
- `artifacts/review_gate.json`: 개발/독립 날짜별 결과와 구성요소별 검토 가능 여부. **자동 운영 승격 허가가 아닙니다.**
- `private/`: 저장 원본과 비교 행. 공개 웹 정적 자산에 포함하지 않습니다.
- `development_run_001/`: 초기 개발 결과·소스 보존. 독립 날짜 개봉 전 확률 가중치와 시간선 정합성 등을 검토해 수정한 과정입니다.

검사는 해당 폴더에서 `python -m unittest -v test_empirical_transport.py`로 실행합니다. 원본 자료는 기존 수집 저장소에서 내려받으며 서울시 실시간 API 호출을 추가로 발생시키지 않습니다.
