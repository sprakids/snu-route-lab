# 서울대 정류장 승하차 자료 확보

확인일: 2026-11-10. 사용자가 지정한 자료 범위는 2026-10-13~2026-11-09이며, 원시 교통카드 대량 다운로드 대신 서울 열린데이터광장 공개 CSV를 우선 사용했습니다. 모델·계수·운영 앱·배포는 변경하지 않았습니다.

## 확보 결과

- **월별 시간대 승하차:** OA-12913의 2026년 10월 원본 15,685,495바이트를 기존 보존본에서 재사용했습니다. 현재 공식 파일 목록의 동일한 10월 파일(순번 115)과 기존 다운로드 해시를 확인했습니다.
- **날짜별 승하차:** OA-12912의 공개 CSV 검색에서 5511·5513·5516·관악02-1·관악02-2·5515·5528·6515를 각각 조회했습니다. 8개 원본을 합쳐 2,107,210바이트입니다. 인증키나 서울시 실시간 위치 API를 사용하지 않았습니다.
- **일별 자료 범위:** 요청한 28일 중 24일이 확보됐습니다. 10월 13일~11월 6일 중 10월 27일이 빠져 있으며 11월 7~9일도 다운로드 응답에 없습니다.
- **10월 27일 대조:** 공식 10월 일별 전체 원본(표시 용량 140.85MB)도 받아 확인했으며, 해당 날짜는 원본에도 없습니다. 파일과 노선별 공개 검색의 겹치는 14,718행은 승하차 수가 모두 일치합니다. 같은 원천의 추출본 대조이며 독립 관측 검증은 아닙니다.

## 해석과 품질 점검

- 시간대 자료는 **월 합계**이며 요일이나 임의의 4주로 나눌 수 없습니다. 일별 자료에는 시간대가 없습니다. 두 자료를 합쳤다고 날짜×시간대 실측이 생기는 것은 아닙니다.
- 정류장 범위는 기존 8개 노선의 공식 정류장 좌표 목록을 기반으로 교내 본구역·기숙사/호암 부속 구역·외부 주변 구역을 구분한 프로젝트 기준입니다. 법적 지적 경계는 아닙니다. 선택 ID와 분류는 `stop_scope.json`에 보존했습니다.
- 같은 정류장을 한 노선이 여러 번 지나는 경우 역명 끝의 정류장 순번을 보존해 합류 과정에서 중복 증폭하지 않았습니다. 일별·월별 복합키 중복은 모두 0입니다.
- **검토 대상:** 5528의 `서울대정문(00999)` 승차 1건이 원자료에 있습니다. 10월 월별 자료와 10월 18일 일별 자료에 같은 기록이 있으나, 순번 999이고 통상적인 노선·정류장 연결과 맞는지 확인되지 않았습니다. 원자료는 유지하며 이 1건을 정규 교내 운행의 근거로 쓰지 않습니다.
- 승하차 수는 모든 이용자의 탑승 사건 수이며 고유 학생 수가 아닙니다. 정류장 대기 시작, 탑승 실패·중도 이탈, 개인별 대기시간, 학생 소속은 포함하지 않습니다. 누락 날짜를 0으로 채우지 않았습니다.
- 기존에 받아 둔 T-data 재차합 집계, 이번 승하차 집계, 개별 교통카드 이용 기록은 서로 다른 단위입니다.
- T-data의 `TAIMS_20261109.zip` 1개는 공개 다운로드 가능 여부 확인 중 보존했으며, 안의 자료 기준일은 11월 5일입니다. 이 파일명 날짜를 실제 이용일로 취급하지 않았습니다. 사용자 지시에 따라 이후 원시파일 대량 다운로드는 진행하지 않았습니다.
