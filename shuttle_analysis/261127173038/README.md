# 윗공대 저녁 수업 후 체류 실험 R261127173038

기준은 연구 R261127170244의 체류·거리별 접근 결합 조건이다. 목요일의 하루 하교 통행 16,517건을 그대로 두고 건물 출발 시각만 바꿔, 제2공학관 19시대 승차를 앞뒤 시간과 함께 비교했다.

**30~60분 체류가 19시 한 시간에는 더 잘 맞았고, 저녁 세 시간의 두 역 방면 오차는 두 조건 모두 소폭 커졌다.** 피크 배차에서 19시 전체 승차는 17.65건에서 27.95건으로 늘어 세 목요일 평균과 기존 모형 사이 격차의 5.4%를 줄였다. 18시 승차는 11.32건 줄어 이미 부족한 시간대의 격차가 커졌다. 두 역 방면 18~21시 MAE는 기존 43.70건, 짧은 체류 43.79건, 긴 체류 43.96건이다. 30~60분 조건은 체류 시각을 검증하기 위한 연구 후보로 보관한다. 다음에 구분할 대상은 마지막 수업 종료 후 남았던 승객과 그날 수업 없이 연구·근무 등으로 윗공대에 있던 승객의 실제 비중이다. [현장조사표](../evening_origin_2026-11-27/현장조사표.md)

## 어떤 학생의 출발을 늦췄는가

300·301·302동에서 18:00을 지나 20:00 전에 종료하는 수업 중 원래 종료 후 30분 이내 또는 일찍 출발하는 집단을 대상으로 했다. 20시 이후 종료 수업은 19시 승차의 원인을 시험하는 이번 범위 밖이다. 관악산역 도달 시각에 별도 조건이 있는 신림선 집단은 기존 출발 시각을 썼다. 대상 102.57명 상당에게 25%의 선택 확률을 적용했으며 이번 추첨에서는 26.17명이 선정됐다. 같은 사람에게 원래 건물 출발 시각부터 30~60분 또는 60~120분을 더했다. 어떤 시간이 실제 분포인지 보여주는 직접 관측은 없다.

두 체류 조건은 같은 학생과 동일한 난수 순위를 사용한다. 하루 인원·개인별 목적지·최초 계획·차량 시각·정원이 같고, 늦어진 도착 이후 대기·재선택·승차는 사건 순서에 따라 다시 계산했다. 목요일 피크 배차는 지연 0분 조건도 재실행해 기존 R의 승차 원장 집계와 대조했다. 기준 배차의 비교군은 보관한 기존 R 원장을 읽었다. 두 배차에서 입력을 생성할 때마다 직전 연구의 개인별 입력 파일과 비교했다. [실험 코드](experiment.py) · [강좌별 적용 인원과 평균 추가 체류](강좌별_체류.csv)
