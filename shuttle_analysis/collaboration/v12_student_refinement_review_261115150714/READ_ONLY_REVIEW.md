# 학생 행동 수정 후보의 정적 재검토

2026-11-15. 비운영 후보 `261115150714`, 구현 부모 `261115144206`.

**앞 후보의 복귀 오류에 대한 차단 조건은 새 소스에 연결됐습니다. 다만 strict-subset 후보 제거에는 추가 정책 반례가 남습니다.** 이 문서는 시험이나 모델을 새로 실행한 결과가 아닙니다. [동결·STARTED 증거](evidence.json)와 소유 에이전트의 시험 보고를 구분합니다.

## 이전 지적의 연결 상태

- 떠나는 현재 node를 `filter_stages(...,allow_current=False)`의 금지 집합에 넣습니다. 실제 도착 이력이 없는 초기 state까지 가상의 방문으로 세지 않는 조건도 있습니다.
- `complete`가 유효한 incumbent를 얻지 못하면 원본 승차 pool을 반환하지 않고 빈 pool을 반환합니다. 수요를 삭제하는 처리가 아니며, 실제 미완료·대기시간은 별도 원장에서 확인해야 합니다.
- 도중 승차 제안 전에 중간 정류장을 visited에 추가한 `resume_probe`로 원래 저장 tail을 검사합니다. 검사 결과가 None인 경우만 제외하므로 정상적인 최종 도보의 빈 stages도 유지합니다.
- `complete_signature`가 서비스별 next_walk와 continuation을 재귀적으로 포함합니다. 후보 key·taste·학생 초기 catalog·초기변경 비교가 이를 사용합니다. 단순 표현 변환과 후속 정책 차이를 구분하려는 연결입니다.
- feasibility cache에 목적지가 포함됐습니다. 최종 snu1km 제한이 다른 목적지의 캐시 결과로 건너뛰어지는 앞 반례를 막습니다.
- 초기 접근 확장은 known walking ID로 제한합니다. 기존 입력에서 차량 운행에만 참조된 ID가 실제 보행 금지 도로였다는 판정과는 구분합니다.
- 추가로 보낼 차량 집계는 이미 처리된 last_stop과 현재 processing_stop을 제외하고, 아직 미처리인 같은 시각 차량은 남깁니다. engine의 처리 시작/끝에서 그 표지를 설정·제거합니다.
- 인내 판정에는 경과시간+예측 첫 승차까지 대기를 쓰고, 도착 시 예상대기가 임계치를 넘으면 기존 무작위 arrival gate를 우회해 재검토합니다. 대안 선택 자체를 강제하는 것은 아닙니다.

이 연결을 앞 후보의 오류가 실제 모든 여정에서 사라졌다는 증거로 확대하지 않습니다. 새 월·화 원장에서 복귀·미완료·정원·FIFO·인원·시간을 확인해야 합니다.

## 추가 정적 반례: 더 큰 승차 pool이 반드시 더 좋은 정책은 아님

`remove_redundant`는 같은 접근 경로에서 작은 완전 서비스 집합이 큰 집합의 strict subset이면, 비용과 무관하게 작은 후보를 지웁니다. continuation을 포함한 identity는 공유 서비스의 동등성을 확인하지만 **집합 포함만으로 전체 정책의 지배관계까지 성립하지는 않습니다.**

현재 예측은 첫 boardable 서비스를 선택하고 실제 호환 차량은 항상 수락합니다. 따라서 다음과 같은 합법적인 조건부 반례가 가능합니다.

|항목|작은 후보|큰 후보|
|---|---|---|
|허용 서비스|A|A와 B|
|공유 A 정책|300초 승차,60초 운행|동일|
|추가 B|없음|60초 승차,1800초 운행|
|첫 호환 차량 수락 시 도착|360초|1860초|

접근·준비는 두 후보에서 같고 양쪽 첫 차량보다 먼저 완료된다고 둡니다. 요금과 최종 도보도 같게 둘 수 있습니다. 작은 후보가 일반화비용까지 더 낮은 경우를 만들 수 있지만 함수는 여전히 작은 후보를 삭제합니다. 초기 city의 첫 승차 최소화와 달리 이 함수는 **변경 후보의 전체 일반화비용 비교**에 쓰입니다.

이 반례를 직접 실행하지 않았으며 현재 입력이나 파일럿에서 발생했다고 주장하지 않습니다. 기존 신규 시험에서 다른 continuation을 가진 공유 서비스의 subset은 보존하는 정의를 확인했지만, 같은 continuation+느린 추가 노선 조건의 시험은 별도 확인이 필요합니다.

추가 서비스를 거부할 수 있는 최적 승차 정책을 정의하거나, 실제 예측 비용을 포함해 지배를 검증하거나, 완전히 같은 정책만 중복 제거하는 방법을 검토할 수 있습니다. 동결본을 제자리에서 고치는 권한으로 해석하지 않습니다.

## 남은 방어 경계

`initial_choice`는 합법적 transit fallback도 하나도 없으면 원본 계획을 유지합니다. 원본이 snu1km 초과 순수 도보이고 초기 mode만 city로 재분류됐던 경우라면, 빈 후보집합에서 긴 원본 도보가 재개되는 함수 계약상의 경계가 남습니다. 현재367집합에서 그런 그룹이 존재하는지는 확인하지 않았습니다. 끝점 검사가 통과했다는 사실만으로 모든 mode·목적지의 비어 있지 않은 합법 대안을 보장하지는 않습니다. 필요하면 준비 검사에서 해당 초기 집단의 fallback 유무를 따로 확인해야 합니다.

예상 총대기 임계치와 기존 실제 경과대기 임계치는 다른 행동 가정입니다. 중앙값20분·개인차·경사/거리 선호는 여전히 시나리오입니다. 새 가정이 학생의 실제 선택을 더 잘 설명하는지는 실측 검증에서 따로 판단해야 합니다.

## 증거의 해석

소유 에이전트는 신규48개+legacy89개, 총137개 시험 통과를 보고했습니다. 이 검토는 이를 재실행하지 않았습니다. 최종 준비 파일의 실제 수치와 소유 에이전트가 먼저 전달한 수치가 다를 수 있어 evidence에 파일별 값을 별도로 기록합니다.

확인한 STARTED는 월·화 regular 두 개입니다. 신규 날짜 정답과 새 운행 실측은 열지 않았습니다. 이전 후보의 실패·소스·동결 입력은 보존하며, 운영 V11·경로 앱 활성 모델·공개 latest의 교체 또는 배포를 승인하지 않습니다.
