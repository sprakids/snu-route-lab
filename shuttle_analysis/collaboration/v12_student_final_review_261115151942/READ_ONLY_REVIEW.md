## 1. 다른 수락 정책을 subset이라는 이유로 지우지 않음

`behavioral_policy.py:26~34`는 `(접근 path ID, complete_signature)`가 같은 후보만 합치고 최저 비용의 항목을 남깁니다. 완전한 signature에는 서비스의 rid·board·alight·next_walk와 재귀 continuation이 들어갑니다. 다른 경로 표현의 pool 순서는 정렬해 비교합니다.

이것은 현재 컴파일된 path·시간·선호를 공유하는 동일 결정 맥락의 중복 제거입니다. 서로 다른 수락 정책의 성능을 증명하거나, 초기 city의 첫 승차 최소 목적을 최종 도착시간 최소 목적으로 바꾸는 수정은 아닙니다.
