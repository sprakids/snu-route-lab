# 수집 관측의 특징과 모형 수정 필요성 검토

사용자 요청: 지금까지 수집된 자료를 이용해 어떤 특징이 보였는지, 어느 정류장/구간 이후 혼잡등급이 늘거나 줄었는지, 하교길 실험실 모형을 수정할 근거가 있는지 검토해 주세요.

- manifest.json의 해시·기간·표본 범위를 먼저 확인합니다. 원본은 변경하지 않습니다.
- 차량·운행·정방향 구간별 중복을 제거합니다. 같은 차량을 연속 조회한 횟수를 독립 표본으로 세지 않습니다.
- 정류장 이름/원문 순번/방향을 대응하고, 연속 정류장 관측과 여러 정류장을 건너뛴 관측을 구분합니다. 정류장 변경이 혼잡 변화의 원인이라고 단정하지 않습니다.
- 노선·요일·시간·정류장별 등급 분포, 관측 결측률, 등급 증가/감소, 지속 시간·회복 구간을 표본 수와 함께 정리합니다. 숫자 0은 미제공이지 빈 차가 아닙니다.
- 관악02의 등급 미제공과 일반버스의 유효 등급을 분리합니다. 만차 플래그는 실제 승차 실패나 실제 줄 인원이 아닙니다.
- 보고서는 단기 관찰 특징 / 개선 후보 / 현재 적용 가능한 수정 / 추가 관측이 필요한 수정으로 구분해 주세요. 별도 날짜 검증이 불가능하면 명시합니다.
- 앱 city_wait의 고정 상류 재차·조건부 FIFO 가정과 원본 v5 배경 승객 미포함 가정을 함께 검토하되, 집계 재차합이나 혼잡등급을 개인 대기 인원으로 환산하지 않습니다.
- 요청 결과물을 이 폴더에 요약 Markdown과 정류장 변화 CSV로 저장해 주세요. 이 검토 요청만으로 원본 모델 계수·배차·앱 코드·공개 배포를 바꾸지는 마세요. 별도로 진행 중인 UI 작업은 기존 사용자 범위를 유지합니다.
