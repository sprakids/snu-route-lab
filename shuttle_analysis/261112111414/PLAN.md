# V12 실측 통합 후보

사용자 지시: V12에 지금까지 확보한 실측 결과를 빠짐없이 연결하고 검증한다. 공개 V11 교체·배포는 새 사용자 명시 승인 전 금지한다.

계보: 운영 기준은 V11의 통행 수요와 정원·피크 두 차량 계약이다. 비운영 구현은 R10 및 261112104829 실측 구간시간 후보의 후속이다. 숫자 YYMMDDhhmmss를 릴리스 식별자로 사용하고 V12는 별도 메타데이터로 둔다.

1. 실측 원문·개정 내역·각종 누락과 기존 승하차 자료를 인벤토리로 고정한다. 자료별로 런타임 입력, 검증 참조, 미식별/미확보를 구분한다.
2. 시내버스는 11/10으로 학습하고 11/11을 날짜 분리 사후점검한다. 이미 기술적으로 탐색한 11/11은 완전히 미사용인 최종 검증일이 아니다. 이후 처음 완료되는 새 날짜를 별도 평가용으로 보존한다.
3. 기존 678개 구간×시간 보정과 fallback을 그대로 계승한다. 구간시간 분포와 변동도 예측 진단에 제공하며, 검출간 시간에 정차를 또 더하지 않는다.
4. 정류장별 통과간격 전체를 예측 참조로 연결한다. 실제 시나리오 공급은 노선별 방향이 확인된 기준 정류장 통과시계에서 만들고, 구간시간을 거꾸로 풀어 첫 모형 정류장 출발시계를 구한다. 차고지 배차로 그대로 복사하지 않는다. 관측 누락과 15초/3600초 경계, 짧은 간격은 별도 표기한다.
5. 혼잡 분포와 같은 차량·회차의 인접 전이는 순서형 상태 확률로만 연결한다. 기존 혼잡 불편 계수에 ‘심한 등급일 확률×승차시간’을 공급하는 선택 시나리오이며, 정원·재차·승하차 인원으로 환산하지 않는다. 결측은 null/가정 상태로 유지한다.
6. 만차표시도 유효 표본 범위와 비율을 예측 진단에 연결하되 숫자 여석으로 바꾸지 않는다. 학습에 사용하지 않은 현장 줄·개인 대기 보고는 최신 수정본을 검증 제약으로 보존한다. 이미 기존 선택에 쓴 보고는 독립 최종 검증이 아니다.
7. 무제한 변경·기본0.3^n 성향과 별도 스트레스는 유지한다. 실제 미래 공급 시계 공유, 반복 경로와 극단 여정은 기존 미해결 항목이며 이번 자료 통합이 해결한 것으로 주장하지 않는다.
8. 동일 공급/시계의 대조군과 V11/R10을 구분한다. 전체 평일의 질량·정원·FIFO·대기열·연속/누적 대기·여정 꼬리·현장 줄 오차를 검사하고, 20분 강제이탈·대기 자르기·수요 삭제로 통과시키지 않는다.
