# 서울대 공대생 중심 셔틀 혼잡 분석: Codex 작업 지침

## 1. 사용자와 목적
나는 서울대학교 산업공학과 학부생이다. 2026 서울공대 데이터 공모전의 후보 주제로, 공대생의 셔틀 대기·혼잡과 정류장 접근 불편을 개선하는 아이디어를 검토하고 있다. 아직 공모전 참가나 제출을 확정한 것은 아니다.

먼저 2026학년도 2학기 수업별 정원과 요일별 종료 시간을 조사하여 수업이 많이 끝나는 시간대를 찾고 싶다. 공대 공모전이므로 전체 서울대 수업을 무차별 합산하지 말고 공대생 관련 수업과 실제 수업 장소를 중심으로 분석해줘.

## 2. 반드시 반영할 사용자 요구
- 윗공대에서 끝나는 수업, 아랫공대에서 끝나는 수업, 인문대·자연대 등 다른 권역에서 열리는 교양을 구분한다.
- 개설 학과와 수업 장소는 별개의 축이다. 공대 개설 강좌라도 다른 건물에서 열릴 수 있다.
- 공대생이 듣는 교양을 고려하되, 교양 정원 전체를 공대생 수로 간주하지 않는다. 수강대상 제한이나 학과별 교양 이수요건으로 관련성을 확인하고, 소속별 실제 수강인원이 없으면 '공대생 수강 가능 후보'라고 표시한다.
- 윗공대 학생들이 셔틀 정류장까지 내려오는 부담에 주목한다. 단, 모든 노선에서 반드시 걸어 내려와야 한다고 단정하지 않는다. 순환셔틀·역방향순환·통학셔틀을 구분하여 실제 이용 가능한 경로를 확인한다.
- 수업 종료 시각과 정류장 도착 시각을 별도로 다룬다. 보행 시간은 근거가 있을 때 사용하고, 미확인 값은 가정별 시나리오로 표시한다.

## 4. 기존 추출에서 확인된 사항과 재검증할 점
- 고유 교과목번호+강좌번호 조합 8,008개. 수업 시간이 있는 강좌 4,503개, 없는 강좌 3,505개.
- 공과대학 개설 1,071개 중 학사 360개, 석박사통합 710개, 석사 1개. 논문 강좌가 많으므로 전체 1,071개가 정규 대면 수업이라고 보면 안 된다.
- 전체 교양 강좌는 1,402개지만 모두 공대생 대상은 아니다.
- 수강신청인원은 전 강좌 0이다. 수강신청 전 자료이므로 실제 인원 또는 실제 수요 0으로 해석하지 말고 분석 가중치로 사용하지 않는다.
- 정원 원문은 대부분 '50 (50)' 같은 형태다. 7,837행의 괄호 안팎 값은 같고, 나머지 171행은 0이다. 두 값을 더하지 않는다. 공식 매뉴얼 검색결과에는 '정원(재학생)' 표기가 있으나 본문 정의는 확인되지 않았다. 먼저 정의를 확인하거나, 바깥값을 사용한 잠정 규칙을 명시하고 원문을 보존한다.
- 강의실 열은 '강의실(동-호)(#연건, *평창)'이다. 다른 캠퍼스와 위치 미확인을 분리한다.
- ⓒ 표시 강좌 195개, 실습반N 표시 슬롯 204개가 있다. 표시 의미와 공동수업·실습집단 여부를 확인한다. 실습반마다 전체 강좌 정원을 복제해서 더하면 과대계상될 수 있다.
- 기존 추출에서 표준 시간 표현의 파싱 및 시간·강의실·형태 대응 오류는 보고되지 않았지만, 의미 해석까지 검증된 것은 아니다. 원본 대조가 필요하다.
- 캠퍼스·대면 여부·공대 권역 필터 및 최종 순위 계산은 완료되지 않았다. 최종 혼잡 시간대 결과는 아직 없다.

## 5. 권장 분석 절차
1. 자료의 기준일과 범위를 확인하고 원본을 보존한다. 최신 자료와 7월 자료를 혼합하지 않는다.
2. 공식 캠퍼스 지도 등으로 건물 번호를 검증한다. 윗공대·아랫공대의 분석상 경계를 명시하고 애매한 건물은 별도 처리한다. 소속 단과대만 보고 위치를 추정하지 않는다.
3. 학부 공대 개설 수업을 우선 분석하고, 공대 대학원 수업 및 공대생 관련 교양 후보는 별도 결과로 제시한다.
4. 한 강좌가 여러 요일에 열리면 요일별로 펼친다. 같은 강좌·요일·시간의 중복 행이나 여러 강의실 표기로 정원을 중복 합산하지 않는다. 긴 수업을 매시간 종료하는 수업으로 쪼개지 않는다.
5. 연속 강의·실습, 실습집단, 공동개설 수업은 따로 검토한다. 자동 병합·제외 규칙과 그 영향을 기록한다. 누락값은 0으로 바꾸지 않는다.
6. 요일별 정확한 종료 시각, 15분 구간, 30분 구간을 집계한다. '끝나는 수업 수'와 '해당 수업 정원 합계'를 따로 계산한다. 권역별·교과 유형별 결과를 분리한다.
7. 상위 시간대의 원본 강좌를 직접 대조하고, 제외된 수업과 정원 확인 비율을 제시한다. 자료 범위가 좁거나 누락이 많으면 전체 최고라고 단정하지 않는다.
8. 확인된 셔틀 정류장·운행 시간과 비교한다. 보행 지연이나 환승을 고려한 정류장 도착 시간대는 원래 수업 종료 집계와 구분한다.
9. 결과로 실제 관찰할 정류장·요일·시간대 후보를 제안한다. 대기 인원, 차량 도착 시각, 탑승·잔류 인원 등을 비식별로 관찰하여 가설을 검증하는 다음 단계를 설명한다.

## 6. 반드시 지킬 해석상의 한계
- 정원 합계는 학생 실인원, 출석 인원, 귀가 인원 또는 셔틀 이용 수요가 아니다. 요일·시간대별 '종료 수업의 정원 합계'로 표현한다.
- 같은 학생이 여러 수업에 등장할 수 있으므로 하루·주간 합계를 고유 학생 수로 해석하지 않는다.
- 수업이 끝나도 다음 수업, 식사, 연구실·도서관 방문 등이 가능하다. 수업 종료만으로 하교를 가정하지 않는다.
- 교양의 공대생 비중과 셔틀 이용률을 임의로 정하지 않는다. 필요하면 가정을 명시하고 민감도 분석으로 구분한다.
- 관찰 자료 없이 '이 시간에 버스를 몇 대 증편해야 한다'고 확정하지 않는다. 수업 데이터는 관찰 시간대를 정하는 근거다.

## 9. 원하는 산출물과 설명 방식
- 먼저 자료 접근과 포함 범위, 최신 여부를 짧게 알려준다.
- 재현 가능한 정제 코드, 정제 자료, 요일·권역별 종료 수업 수 및 정원 합계 표를 제공한다.
- 유용하면 두 지표를 별도 히트맵으로 보여준다. 수요로 오해되는 제목은 피한다.
- 상위 후보 시간대와 근거 강좌, 제외 기준, 불확실성을 설명한다.
- 공모전 문제 정의에 연결할 수 있는 결론과 추가 관찰 계획을 제안한다. 실제 신청서 초안은 요청받은 뒤 작성한다.
- 한국어로 설명하고 첫 줄은 '할루시네이션 방지 O'로 시작한다. 확인 사실·추정·추가 확인 필요를 구분하며 수치와 주요 판단에 출처를 붙인다. 분석 단계별로 무엇을 하는지와 왜 필요한지를 설명하고 마지막에 검산 결과를 알린다.
