# 하교길 아이콘 v2 설계

사용자 요청: 서울대 로고를 위쪽으로 옮기고 요소를 확대해 작은 크기에서도 아이콘으로 알아볼 수 있게 한다. 생성 전에 구성 기준을 정한다.

- 의미 순서: 위의 서울대에서 출발해 아래의 집으로 이동한다.
- 위계: 서울대 심볼이 가장 큰 주 요소, 집이 다음 요소, 방향 화살표가 둘을 연결한다.
- 배치 목표: 상단 중앙 서울대 심볼 너비 약 64~68%, 하단 중앙 집 너비 약 56~60%. 전체 구성은 캔버스 높이 약 86~90%를 사용한다. 비율은 생성 지침이며 결과의 실측 수치가 아니다.
- 방향: 로고 오른쪽에서 집 쪽으로 내려가는 짧고 굵은 화살표. 로고 내부나 집의 윤곽을 가리지 않는다.
- 형태: 집은 지붕·외곽·문만 남긴다. 창문·글자·지도·버스 등은 추가하지 않는다. 심볼의 월계관·중앙 교문·책의 구조를 유지하고 작은 글자를 별도의 장식으로 강조하지 않는다.
- 색: 기존 사이트의 남색 #19398A와 흰색을 사용한다. 불투명한 바탕, 질감·그림자·광택은 배제한다.
- 검토: 48px와 64px에서 서울대 심볼의 전체 형태와 집을 구분하고, 학교→집의 방향을 읽을 수 있는지 실제 크기의 웹 미리보기로 확인한다. 심볼 안의 작은 라틴어 문구를 읽는 것은 판정 기준이 아니다.
- 원본 보존: v1은 변경하지 않고 v2를 별도 저장한다. 운영 사이트에 자동 적용하지 않는다.
