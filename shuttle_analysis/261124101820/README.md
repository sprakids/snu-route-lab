# 기숙사와 대학동 도보 선택, 수업 종료별 하교확률

## 기숙사행

사용자가 대학동과 기숙사까지의 거리가 비슷하다는 점을 들어 기숙사행 도보 확률을 높여 달라고 요청했습니다. 모형에서는 같은 건물에서도 학부 기숙사와 대학원 기숙사까지의 보행거리가 다를 수 있으므로 출발지와 목적지 쌍별로 계산합니다. 기존에 걸어가는 사람에 더해, 첫 계획에서 차량을 이용하던 기숙사행에 아래 전환 확률을 적용합니다. 중간 구간은 선형으로 연결합니다. ## 대학동행과 하교 피크

대학동행에서는 원래 행정관 대학동 셔틀을 첫 교통수단으로 택한 집단에서 도보·개인형 이동장치로 바꾸는 목표 확률을 82%로 적용했습니다. 이 수치는 전체 대학동 거주자 중 걷는 비율과 분모가 다릅니다. 11월 23일 월요일 행정관 16:59분 중 관측된 만차 출발과 차량 밖 잔여 1명을 함께 고려했습니다. 같은 요일의 모형에서 가장 가까운 출발은 17:00입니다. 피크를 강화한 상태에서 다른 설정도 대조했으며, 보정에 사용한 같은 관측은 독립적인 정확도 검증에 쓸 수 없습니다.
