개인정보 처리방침

시행일 2026년 11월 9일 · 방침 버전 1.0

서울대 하교길은 2026학년도 2학기 서울대학교 산업공학과 산업공학의 이해 7조가 운영하는 경로 비교 서비스입니다. 회원가입 없이 이용하며, 위치 권한을 허용하지 않아도 건물 검색과 출발지 선택으로 경로를 찾을 수 있습니다.

운영자·개인정보 문의 담당: 김예준
문의: sprakids@snu.ac.kr

1. 처리하는 정보와 목적

항목사용 목적보관 기준
현재 위치허용한 경우 기기에서 위도·경도, 위치 정확도와 확인 시각을 받아 지도에 표시합니다. 현재 위치로 검색할 때 좌표를 서버에 전송해 경로를 계산합니다.개인 위치 이력을 데이터베이스에 저장하지 않습니다. 브라우저 메모리와 서버의 임시 보행 캐시에 남을 수 있으며, 페이지 종료 또는 캐시 교체·서버 인스턴스 종료 시 제거됩니다.
검색 조건선택한 건물·정류소 또는 좌표, 목적지, 출발 시각, 경로 선호도와 선택한 경우 대기 비교 조건을 계산에 사용합니다.이름·계정에 연결한 검색 이력을 저장하지 않습니다. 계산과 임시 캐시에 사용합니다.
기기 설정기본 선호도, 셔틀 포함 여부, 화면 모드, 큰 글씨와 동작 효과 설정을 기억합니다.이용 중인 브라우저의 로컬 저장소에 보관하며, 설정 초기화 또는 사이트 데이터 삭제 시 제거됩니다.
직접 제출한 이동 기록경로 구분 코드, 검색 당시 예상시간, 실제 이동시간, 만족도, 착석 여부, 제출 시각과 기록 번호를 저장해 예상시간 오차를 분석합니다.수집일 기준 365일이 지난 자료를 정리 작업에서 삭제합니다. 이름·이메일·정확한 위치 좌표는 이동 기록에 저장하지 않습니다.
이메일 문의보낸 이메일 주소와 문의 내용을 답변·권리행사 처리에 사용합니다.문의 처리가 끝나 보관할 필요가 없어지면 삭제합니다. 법령에 따른 보관이 필요한 경우 해당 기간을 적용합니다.
접속 관련 정보웹 호스팅·지도·보안 서비스가 요청 시 IP 주소, 브라우저 정보, 접속 시각과 요청한 자원 등의 접속 정보를 처리할 수 있습니다.각 제공자의 정책과 실제 서비스 설정에 따릅니다. 앱의 자체 요청 로그에는 요청 경로만 기록하며 요청 본문과 정확한 위치를 직접 기록하지 않습니다.

현재 위치는 브라우저에서 허용한 경우에 사용하며, 위치 대신 건물·정류소를 선택할 수 있습니다. 이동 기록 제출과 이메일 문의는 이용자가 선택하는 기능입니다. 서비스 제공, 요청한 계산과 기록 분석, 문의 처리 외의 광고·개인별 마케팅 목적으로 사용하지 않습니다.

2. 이동 기록의 이용과 공개 범위

제출된 이동 기록은 예측 오차 검증에 사용됩니다. 기록 번호·제출 시각·경로 구분 코드·이동시간·만족도·착석 여부는 서비스의 기록 조회 API에서 표시될 수 있습니다. 기록은 이름이나 계정에 연결하지 않지만, 시간과 이동 특성으로 다른 정보와 결합될 가능성까지 없는 완전한 익명 자료라고 단정하지 않습니다. 제출하지 않아도 길찾기를 이용할 수 있습니다.

3. 외부 서비스와 처리위탁

제공자이용 내용관련 안내
Vercel Inc.웹페이지 전달, API와 경로 계산. 경로 계산 서버는 서울 리전을 사용하며, 요청한 검색 조건과 접속 정보가 처리됩니다.Vercel 개인정보 안내
Cloudflare, Inc.시내버스 공용 자료 수집·저장, 캐시, 사용량 관리와 직접 제출한 이동 기록 저장. 이 저장소로 기기의 정확한 위치 좌표를 전달하는 기능은 사용하지 않습니다.Cloudflare 개인정보 안내
OpenStreetMap Foundation / 카카오선택된 지도 제공자에 지도 타일 또는 SDK 요청과 접속 정보가 전달됩니다. 지도 화면이 보여 주는 영역이 요청에 포함될 수 있습니다. 카카오 지도 설정이 없으면 OpenStreetMap 지도를 사용합니다.OpenStreetMap · 카카오

4. 국외 처리에 관한 안내

Vercel·Cloudflare·OpenStreetMap Foundation은 국외 사업자이며, 서비스 제공 과정에서 미국·유럽 등 해당 사업자의 운영 지역을 통해 접속 정보와 위 표의 처리 항목이 전송·처리될 수 있습니다. 전송은 웹·API 요청 시 네트워크 통신으로 이루어집니다. Vercel 계산 리전이 서울이라는 사실이 모든 접속 로그와 외부 서비스 자료의 국내 보관을 뜻하지는 않습니다.

현재 플랫폼의 국가별 실제 저장 위치와 세부 로그 보존기간은 확인이 완료되지 않았습니다. 이 항목은 각 제공자의 정책·계약과 계정 설정을 확인한 뒤 구체화해 방침에 반영합니다. 관련 설명이나 이용 중단·삭제 요청은 운영자에게 문의할 수 있습니다. 국외 서비스를 통한 처리를 원하지 않으면 사이트 이용과 이동 기록 제출을 중단할 수 있습니다.

5. 로컬 저장소·쿠키와 이용자의 선택

앱은 광고·사용자 추적용 쿠키를 별도로 설정하지 않습니다. snu-homebound-theme-v1에는 화면 모드, snu-route-preferences-v1에는 경로·접근성 기본값을 저장합니다. 여기에 좌표, 검색 이력, 이름과 이메일은 저장하지 않습니다. 외부 지도·호스팅 서비스가 별도로 처리하는 정보는 해당 제공자의 안내를 확인할 수 있습니다.

  • 설정의 “이 기기의 설정 초기화”는 위 설정만 제거합니다. 서버에 제출한 이동 기록과 브라우저의 위치 권한은 삭제하지 않습니다.
  • 현재 위치 사용을 중지하려면 브라우저의 사이트 권한에서 위치를 차단하거나 건물·정류소를 직접 선택해 주세요.
  • 로컬 저장소를 차단하면 설정이 다음 접속까지 유지되지 않을 수 있습니다.

6. 열람·정정·삭제·처리정지 요청

개인정보의 열람, 정정·삭제 또는 처리정지에 관한 요청은 sprakids@snu.ac.kr로 보낼 수 있습니다. 운영자는 본인과 대상 자료를 확인할 수 있는 범위에서 관련 법령에 따라 처리합니다. 회원 계정 없이 제출한 기록은 특정에 어려움이 있을 수 있으므로 기록 번호나 제출 시각 등 확인에 필요한 최소 정보를 알려 주세요. 문의 과정에서 주민등록번호·비밀번호 등 불필요한 정보를 보내지 마세요.

만 14세 미만 이용자의 이름·연락처를 가입 절차로 수집하지 않습니다. 별도의 개인정보를 보내거나 권리행사를 요청하는 경우 필요에 따라 법정대리인 확인 절차를 안내할 수 있습니다.

7. 파기와 안전한 처리

보관 목적과 기간이 끝난 서버 기록은 정리 작업에서 삭제하며, 로컬 설정은 초기화 시 해당 저장 항목을 제거합니다. API 인증키는 서버 환경에서 관리하고 브라우저에 공개하지 않습니다. 저장소 접근은 서버 인증을 사용하며, 정확한 위치와 검색 조건을 포함하는 경로 응답은 공용 캐시에 저장하지 않도록 설정합니다.
