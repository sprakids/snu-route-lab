# 사용자 추가 지시: 프로토타입 반복 개선과 운영 교체 승인

지시일: 2026-11-10 (한국시간)

사용자 원문:
> 프로토타입이 20분 대기 기준을 충족을 못시켜서 폐기된 것 같은데, 만족시키지 못한 원인을 파악해서 그것을 충족시키도록 계속 수정을 거듭하라고 해줘. V11과의 교체는 내가 허락하기 전까지는 하지 말라고 해줘

## 실행 지시

프로토타입의 현재 상태가 폐기/미채택/독립검증불가 중 무엇인지 확인하고 실패 증거를 보존한다. 20분 연속 정류장 대기 초과의 발생 조건과 원인을 추적해 수정·검증을 반복한다. 앞서 요청한 관측 기반 운행시간 보정 결합 실험도 유지한다. 운영 V11과 동일 조건의 대조군을 유지한다.

20분 기준은 기존에 사용한 연속 정류장 대기 정의를 유지한다. 누적 여정 대기와 섞거나, 같은 물리적 줄의 호환 노선 전환 때 시계를 초기화하거나, 20분에 강제 이탈·인원 삭제·인위적 공급 증대로 통과시키지 않는다. 실제 대안을 따라 이동한 후의 보행·추가 대기·총시간과 전체 가중 흐름 수지·정원·FIFO를 함께 검사한다. 미완료/검열과 준비 전 취소는 구분하여 보존한다.

## 운영 교체 권한: 사용자 명시 승인 필수

이번 지시는 앞선 '실측에 더 잘 맞으면 교체'의 자동 교체 허용보다 우선한다. 프로토타입이 20분 기준 또는 정확도 비교를 통과해도 사용자가 명시적으로 승인하기 전에는 V11을 교체하지 않는다.

운영 경로 앱의 활성 모델, 실험실 기본 모델, 공개 routing-model/latest.json을 프로토타입으로 전환하지 않는다. 별도 비운영 실험·파일럿·검증·검토 가능한 결과 준비는 계속 진행한다. 검증이 끝난 구체적 결과를 제시하고 운영 교체 직전에 사용자 승인을 받는다. 현재 유지할 운영 계열은 capacity_v11이다.
