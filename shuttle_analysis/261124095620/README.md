# 대학동행 도보·개인형 이동장치를 반영한 R모형

R261124095620은 공개 기본 엔진 V11을 바탕으로 만든 평일 비교 모형입니다. 대학동 거주자 한 분은 평소 집까지 걷거나 개인형 이동장치를 이용하고 셔틀은 드물게 탄다고 설명했습니다. 개인별 습관 차이를 고려해, 이 경험은 도보 선택을 늘리는 방향의 근거로 사용했습니다. 대학동 전체 거주자의 수단별 비율과 개인형 이동장치의 가용 대수는 미측정입니다. [거주자 진술과 적용 범위](../field_observations_2026-11-24/daehak_walk_pm.json)

## 출발할 때 선택하는 수단

대학동이 목적지이고 V11에서 행정관 대학동행 셔틀을 첫 교통수단으로 골랐던 이동이 대상입니다. 이 집단이 출발지에서 집까지 곧바로 걷기로 바꾸는 평균 목표 확률을 앞선 R의 50%에서 60%로 높였습니다. 10%포인트는 개인 경험을 제한적으로 반영하기 위한 모형 가정입니다. 같은 거리·같은 학생 표본에 두 설정을 적용해 어느 이동이 추가로 도보를 선택하는지 비교했습니다.

보행 경로 500m까지는 전환 확률이 같고 이후에는 거리가 길어질수록 낮아집니다. 개인형 이동장치 이용도 도보 범주에 포함하고, 출발지에서 대학동 목적지까지의 동일한 보행 경로와 소요시간을 적용합니다. 따라서 실제 개인형 이동장치가 절약하는 시간은 계산에 들어가지 않습니다. [거리별 선택 함수](../261123191229/candidate.py) · [보행 경로](../261123191229/walk_catalog.json) · [요일별 경로·시간 검산](choice_verification.json)

출발 계획에서는 바로 걷기를 선택한 비율을 집계합니다. 완료된 이동에서는 줄을 기다리다가 걸어서 귀가한 사람까지 포함해 마지막까지 차량에 한 번도 타지 않은 비율을 집계합니다. 대학동 셔틀 탑승 비율은 모의 이동을 마친 기록에서 도중에 해당 셔틀에 한 번이라도 탄 이동을 셉니다. 각 비율의 분모는 해당 요일의 대학동행 전체 가중 이동입니다. [출발 계획·대기 비교](요일별_도보전환_비교.csv) · [기본 배차의 완료 이동](대학동_완료이동_수단별.csv)

## 평일 기본 배차에서 대학동행이 이용한 수단

각 이동을 집까지 추적했습니다. 대학동행 가중 이동 10,709건 상당을 분모로 하고, 같은 요일을 한 번씩만 포함했습니다. 줄에 섰다가 차량을 타지 않고 귀가한 이동도 도보·개인형 이동장치에 들어갑니다.

|요일|도보·개인형 이동장치, 이전 → 수정|대학동 셔틀에 한 번 이상 탑승, 이전 → 수정|
|---|---:|---:|
|월|33.6% → 39.5%|37.0% → 31.0%|
|화|32.0% → 37.9%|37.2% → 31.3%|
|수|32.9% → 39.0%|38.8% → 32.7%|
|목|33.0% → 39.3%|37.5% → 31.3%|
|금|35.0% → 40.7%|35.4% → 29.7%|
|평일 합계|33.1% → 39.1%|37.5% → 31.4%|

월~금 기본 배차에서 차량을 타지 않고 귀가한 대학동행은 약 644건 늘었습니다. 수정 후 다른 교통편만 탑승한 비중은 29.5%입니다. 기본·피크 배차 모두에서 출발한 가중 수요를 끝까지 추적했고 정원 초과는 0건이었습니다. 10개 실행에서 한 정류장의 최장 연속 대기는 18.16분이었습니다. [요일별 완료 이동 원장 집계](대학동_완료이동_수단별.csv) · [10개 실행 비교](comparison.json)

## 재현

프로젝트의 Python 환경에서 이 폴더의 다음 명령으로 월요일 기본 배차를 계산하거나 검증을 마친 결과를 조회할 수 있습니다. 다른 평일도 같은 확률 모형을 적용합니다. `regular`와 `peak`는 기존 V11의 두 배차 계획입니다.
