정원을 적용한 이동 재생

대형 셔틀 60명은 사용자 지정 정원입니다. 공식 25인승인 역순환은 25명으로 구분합니다. 먼저 도착해 승차 준비 20초를 마친 흐름부터 태우며, 내린 뒤 남은 자리에 승차합니다. 302동 승객은 301동에서도 자리를 차지합니다.

빨간 점은 만차로 못 탄 흐름입니다. 다음 버스에도 자리가 없으면 계속 남습니다. 실제 탑승 시각에 맞춰 이후 보행·환승도 늦어집니다. 막차 뒤 잔류도 표시하며, 경로 재선택이나 포기는 가정하지 않았습니다.

15~19시 최소 간격 시나리오는 입구역 3분·순환 5분입니다. 기준은 4분·6분이며, 대학동 10분·역순환 20분과 나머지 시간대는 같습니다. 동일한 예시 출발시각 규칙으로 비교합니다. 실제 출발·회차시간·차량 배치의 실행 가능성을 확인한 최적화는 아닙니다. 야간은 기존 계산의 2대 동시 출발 가정을 유지하며 각각 60명으로 처리하지만, 내부 동시 출발표는 미확보입니다.

앞선 이동 모형의 대표 난수시드 20261106의 경로 선택을 유지했습니다. 전체 가중 이동량으로 정원을 계산한 뒤 점을 줄여 표시하므로 점 1개는 약 2명 상당이며, 실제 학생 수·GPS가 아닙니다. 교외 목적지의 과거 참고 비중, 기숙사 19.49%, 수업 직후 이동 50% 가정을 유지합니다.

수업 외 승객·교직원·외부 방문객·실제 도로 정체는 미반영입니다. 교내 셔틀의 앞 정류장부터 모델에 포함된 승객만 합산하며, 시내버스 정원은 제한하지 않습니다. 순환 노선의 두 번째 펼친 구간은 기존 탑승객 하차만 처리합니다. 차량 ID는 출발 회차를 구분하며 실제 차량의 재회차·기사 근무는 자료가 없습니다. 차량 속도는 사용자 지정 가정으로 교내 최고40km/h, 교외 목표65km/h입니다. 저장된 캠퍼스 경계·도로 거리·가속과 감속1m/s²·정류장15초 정차를 적용했습니다. 실제 속도나 법정 제한속도를 조사한 값은 아닙니다.
