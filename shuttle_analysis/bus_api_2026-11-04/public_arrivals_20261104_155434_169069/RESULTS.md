# 서울대 경유 버스 주간 조회 결과

수집시각: **2026-11-04 15:54:34 KST**. 서울시 공식 모바일 버스정보 웹 조회 인터페이스에 5개 노선을 각각 한 차례 요청했다. API 키나 포털 로그인은 사용하지 않았다. 승인받은 버스위치 OpenAPI와 별개의 조회 경로다.

도착시간은 수집 당시의 제공기관 예측값이다. 재차인원은 제공기관이 반환한 값이며 별도 실측으로 검증하지 않았다. 마을버스의 값 5를 혼잡 등급으로 해석하면 안 된다. 출발대기도 승객 0명이나 여유 상태를 뜻하지 않는다.

## 해석 근거

[서울시 버스도착정보조회 서비스 공식 명세](https://www.data.go.kr/data/15000314/openapi.do)의 구분값을 원문 응답과 대조했다. 명세 사본은 상위 `sources/arrival_api_documentation.html`에 보존했다.

- `rerdie_Div1/2=4`일 때 `reride_Num1/2`는 혼잡도다. `0=정보 없음, 3=여유, 4=보통, 5=혼잡`이다. 5511·5513·5516의 여섯 차량은 모두 구분값 4, 값 3이었다.
- `rerdie_Div1/2=2`이면 재차인원 항목이다. 공식 명세는 노선유형 6인 서울 광역버스에서는 잔여좌석수일 수 있다고 구분한다. 이번 관악 마을버스는 노선유형 2이며, 혼잡도 등급으로 변환하지 않았다.
- `vehId=0`인 관악02-2 두 번째 슬롯은 미배정으로 처리했다.
- 제공시각은 응답의 `mkTm`을 사용했다. 수집시각과의 차이는 6.2~29.2초다.

실제 요청 예시:

```http
POST http://m.bus.go.kr/mBus/bus/getArrInfoByRoute.bms
Content-Type: application/x-www-form-urlencoded

stId=120000174&busRouteId=100100250&ord=66
```

공식 웹사이트의 조회 방식은 상위 `sources/mobile_commbus.js`에서 확인했다. 이 인터페이스의 장기 운영 적합성·안정성·호출 한도는 이번 한 차례 성공으로 보장되지 않는다.

새벽 00:32 자료는 노선별 차량위치 조회이고 이번 자료는 특정 정류소의 다음 두 도착예정 버스 조회다. 표본이 다르므로 차량 수 증가나 혼잡 변화량을 직접 계산하지 않았다. 이번 결과는 정류장 대기열, 승차 실패 확률, 수업 종료 효과 또는 경로 추천 정확도의 검증 자료가 아니다.

## 키 보관 상태

사용자가 키 보관을 요청해 상위 `credential_store.py`를 준비했다. Windows CurrentUser DPAPI로 암호화하며 프로젝트 바깥 `%LOCALAPPDATA%\SnuTransit\credentials\seoul_bus_service_key.dpapi`에 보관하도록 설계했다. `fetch_snapshot.py`는 저장된 키를 자동으로 읽도록 연결했다.

15:54 조회 시점에는 합성값을 이용한 암호화·복호화 일치, 평문 미포함, 손상 거부 검증만 통과했으며 실제 키는 저장 전이었다. SNU 계정에 연결된 Chrome 프로필의 포털 세션이 만료돼 있었고 당시 로그인 화면은 상위 `snu_profile_login_required.jpg`에 보존했다.

**후속 작업 완료:** 사용자가 보안문자 인증 진행을 확인한 뒤 포털 로그인과 기존 키의 암호화 저장을 완료했다. 저장된 키로 16:03에 5개 노선의 OpenAPI 호출도 성공했다. [실제 키 저장 검증 기록](../credential_storage_status.json), [16:03 결과](../snapshot_20261104_160357_811116/RESULTS.md). 이 문서의 15:54 공개 웹 조회에는 키를 사용하지 않았다.

[Microsoft DPAPI 문서](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)에 따라 현재 Windows 사용자 범위를 사용한다. 키 자체를 소스, 보고서, 명령줄 인수 또는 일반 로그에 넣지 않는다. 상시 수집·예약 작업은 만들지 않았다.
