2026-11-07. 계획·코드·고정 예측을 먼저 검토해 frozen_code_review_checks.json을 저장한 뒤, 이미 완료된 평가의 원 관측값을 읽어 산술을 대조했습니다. 모델·계수·튜닝 선택·시간·공간 범위를 수정하지 않았습니다. API 호출과 키 접근은 없습니다.

## 검산 결과

- 미사용 목표 날짜6일의 원 JSON 1,554행·전체 시간 셀37,296개를 읽어 날짜·노선·순서·끝점·시간의 관측값을 확인했습니다.

- 주 범위는6일×125구간×11시간=8,250셀입니다. 관측 null17셀을 모든 모형에서 같이 제외해8,233셀을 비교했습니다. 11월2일은1,375셀 모두 유효하고, 10월12~16일은6,875셀 중6,858셀입니다. null을0으로 바꾸거나 모형0·관측양수 셀을 제거하지 않았습니다.

세부 근거는 evaluation_metric_review.json, 재현 스크립트는 verify_evaluation_metrics.py입니다. 고정 예측의 수치 일치를 확인한 것이며 과거 모든 파일의 열람 시점까지 독립적으로 입증한 감사는 아닙니다.
