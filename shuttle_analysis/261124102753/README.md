# 관악산역을 포함한 서울대학교 평일 하교 모형

R261124102753은 서울대입구역·낙성대역·기숙사·대학동과 함께 신림선 **관악산(서울대)역**을 하교 목적지로 처리합니다. 강의실에서 출발한 학생들이 같은 차량과 대기열을 이용하고, 버스 정원과 선착순 승차 규칙이 모두에게 적용됩니다. 기본 배차와 피크 배차는 같은 학생들의 출발 계획을 사용합니다.

## 기숙사까지의 거리와 도보 선택

출발지에서 기숙사까지의 보행거리 500m 이내에서는 기존 차량 이용 계획을 도보로 바꿀 확률을 80%로 두었습니다. 500m를 넘으면 연속적인 지수함수로 낮아져 1km에서 25%, 1.5km에서 4%가 됩니다. 거리는 155개 출발지·기숙사 쌍의 보행망 경로를 썼습니다. 각 학생 표본에는 이전 R과 동일한 난수를 사용합니다. 이 확률은 사용자가 요청한 거리 선호를 수치화한 가정입니다.

| 기숙사까지 보행거리 | 이전 R | 통합 R |
|---|---:|---:|
| 500m 이내 | 30% | 80% |
| 800m | 24% | 44.8% |
| 1km | 15% | 25% |
| 1.5km | 4% | 4% |
| 2km | 1.5% | 0.44% |

두 기숙사에 같은 거리 함수를 적용합니다. 학부·대학원 기숙사의 도보 비중은 수업 건물의 위치와 수강인원에 따라 달라집니다. [거리별 확률 그래프](기숙사_거리별_도보전환.svg) · [확률 함수](dorm_distance.py) · [요일별 도보 선택과 완료된 이동](요일별_기숙사도보.csv)

## 신림선 접근 수요

11월 5일 목요일 15~19시 관악산역 전체 승차는 1,295건이었습니다. 교내 시내버스에서 직접 환승한 87건과, 오전 교내에서 하차한 뒤 오후 첫 카드 승차가 관악산역이었던 125건을 바탕으로 학생 비중과 관측 포착률을 가정해 320건을 산정했습니다. 카드만으로 학생 신분과 하교 목적을 식별할 수 없어 320건은 기준 시나리오입니다. [카드자료 분석과 산식](../sillim_ridership_2026-11-24/신림선_학생_하교수요의_범위.md) · [시간별 목표](../sillim_ridership_2026-11-24/scenario_320.json)

목요일 15·16·17·18시대의 목표는 각각 44·55·70·151건입니다. 서울대입구역 또는 낙성대역으로 향하던 이동 중 같은 시간대에 관악산역에 접근 가능한 이동을 재배정합니다. 카드자료를 참조한 시내버스 환승 집단과 도보·무료 교내셔틀 접근 집단에 대해 시간대별로 따로 계산합니다. 다른 요일은 각 집단의 목요일 배정률을 그 요일 시간표에서 가능한 이동 수에 적용했습니다. 다른 요일의 수치는 외삽값입니다. [요일별 분모와 목표](inputs/weekday_targets.json)

전체 출발 수요, 출발 건물과 이동 시작 시각은 보존합니다. 기숙사·대학동 귀가 수요에서 관악산역 수요를 차감하지 않습니다. 역까지 직접 걷거나, 교내셔틀·시내버스를 타고 노선에서 하차를 허용한 정류장에서 역까지 걷도록 했습니다. 역 운영사 지도 기준점 도달을 역 진입 시각으로 근사합니다. 개찰구까지의 실내 이동과 열차 대기·승차는 추가 관측이 필요합니다. [역과 접근 경로의 기준](../sillim_r320_experiment_2026-11-24/README.md)

## 비교와 재현

통합 R의 모든 실행에서 신림선이 기본으로 포함됩니다. 같은 기숙사 확률과 차량 공급으로 신림선 재배정만 뺀 대조 실행을 각 요일·배차에 짝지었습니다. 정류장 대기 총량의 단위인 인·분은 10명이 한 정류장에서 3분 기다리면 30인·분으로 집계됩니다. [평일 통합 하교 요약](평일_통합하교_요약.csv) · [정류장별 대기 총량 변화](정류장별_신림선_통합효과.csv) · [목적지별 이동](요일별_목적지수요.csv)

프로젝트 Python 환경에서 다음과 같이 실행합니다.

```powershell
python -B -X utf8 run_integrated.py --day 목 --service regular
```

같은 명령에 `--without-rail`을 붙이면 비교용 대조군을 실행합니다. `--prepare`는 요일별 재배정과 지도의 공통 경로 자료를 생성합니다. `report.py`는 10개 통합 운행과 10개 대조 운행의 검증된 결과를 집계합니다. [통합 실행 코드](run_integrated.py) · [선택·배정 코드](model.py)
