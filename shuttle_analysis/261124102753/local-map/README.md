# 신림선 통합 하교 지도

[현재 시각으로 로컬 지도 열기](http://127.0.0.1:8794/) · [목요일 17시 관악산역 보기](http://127.0.0.1:8794/?day=thu&scenario=regular&minute=1020&destination=gwanaksan_4411) · [금요일 17시 관악산역 보기](http://127.0.0.1:8794/?day=fri&scenario=regular&minute=1020&destination=gwanaksan_4411)

기본 주소는 서울의 현재 요일·시각과 피크 배차로 열린다. 평일 재생 시간(11:20~23:10)에는 실제 1초마다 지도 시각도 1초씩 진행한다. 시간 밖에는 가까운 경계 시각, 주말에는 금요일 자료를 일시정지 상태로 보여 준다. 목·금 예시 링크는 오후 5시 기준 배차에서 일시정지 상태로 열린다.

요일은 월~금, 배차는 기준·피크 중에서 고를 수 있다. 전체 목적지에서는 서울대입구역·낙성대역·대학동·기숙사·관악산(서울대)역으로 가는 학생들을 한 지도에 표시한다. 목적지를 하나 고르면 해당 학생들의 이동과 대기 표본을 볼 수 있다. **이 시각 경로 예시 보기**는 선택한 지도 시각에 가장 가까운 출발 표본 하나의 실제 모의 이동 경로와 도보·대기·차내시간을 보여 준다.

목적지별 하루 인원은 전체 모의 통행 원장에서 합산한다. 지도 위 점 하나는 약 2명을 나타내는 표시 표본이다. 차량 차내 인원, 승차지 대기 수치와 그래프는 차량과 정류장을 공유하는 모든 목적지의 합계다. 기숙사행 이동은 하나로 선택하고 학부·대학원 생활관은 지리적으로 구분해 표시한다.

## 실행

이 폴더에서 다음 명령을 실행한 뒤 위의 로컬 주소를 연다. 기본 포트는 8794다.

```powershell
python serve.py
```

연구 모델 **R261124102753**의 공용 지도와 평일 10가지 재생 파일은 상위 폴더의 [viewer-data](../viewer-data)에 있다. 요일·배차별 경로 번호는 모두 같은 공용 지도 파일을 기준으로 한다. 지도 테마, Leaflet, 이동 애니메이션과 정류장·그래프 구성은 기존 하교길 실험실을 재사용한다.

## 길찾기 모델과의 자료 연결

관악산(서울대)역의 목적지 키는 `gwanaksan_4411`, 역 코드는 `4411`, 지도 지점은 북위 37.468964도·동경 126.945242도다. 모형의 도착은 역 지도 지점에 닿은 시각이다. 교내에서 걷거나 시내버스·교내셔틀을 탄 뒤 걸어서 도달할 수 있다. 개찰구까지의 실내 이동과 신림선 열차 대기는 추가로 계산해야 한다.

[길찾기 연구용 역 접근 통계](http://127.0.0.1:8794/station-access.json)는 기준·피크 배차, 평일, **역 도달 시간대**, 실제로 이용한 접근 수단 순서로 집계했다. `arrivals`는 도달 인원, `access_person_minutes`는 건물 출발부터 역까지의 총 인·분, `wait_person_minutes`는 그중 정류장 대기 인·분이다. 각각 도달 인원으로 나누면 해당 집단의 평균 분이 된다. 값은 통합 모형의 결과이며 개별 사용자의 실시간 승차 예상과는 용도가 다르다. 목요일은 카드 자료를 바탕으로 320명을 설정했고, 다른 평일은 각 요일의 출발 가능 수요에 비례해 배정했다.

재생 자료가 바뀌면 기존 시뮬레이션과 같은 Python 환경에서 `python build_stats.py`를 실행한다. 아직 계산 중이라면 `python build_stats.py --wait`를 사용한다. 이 명령은 검산이 끝난 원장만 읽어 목적지별 통행, 30분 단위 정류장 대기표, 역 접근 통계를 재생성한다. [통계 생성 코드](build_stats.py)
