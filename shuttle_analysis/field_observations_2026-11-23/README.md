# 11월 23일 월요일 셔틀 관측

## 12:20 행정관 설입행

사용자가 전달한 탑승 경험 1건입니다. 날짜·방향·승차지는 후속 답변 ‘11/23 서울대입구역행 행정관 셔틀’로 확인했습니다.

- **탑승 경험:** 정류장 도착 직후 탑승. 대기시간은 정성적으로 거의 없었으나, 정확히 0초라는 측정이나 몇 초 이하라는 수치는 없습니다.
- **줄 해석:** 사용자의 요청에 따라 ‘줄은 있었고, 그 승차 기회에서 탑승 가능한 인원 범위였다’로 분류합니다. 줄 인원을 직접 센 관측은 아닙니다.
- **시각:** 12:20 안의 초는 미상입니다. 12:20:00이나 12:20:30으로 고정하지 않습니다. 분 안의 균등 분포도 비교 시 별도 선언할 가정입니다.
- **미측정:** 정확한 줄 인원, 차내 인원, 당시 잔여 정원, 차량 식별자, 도착·출발 초, 다른 사람들의 대기시간.

즉시 탑승은 개인의 대기 경험이며, 줄이 0명이었다는 뜻이 아닙니다. 버스가 정차 중이거나 도착 시각이 맞으면 양의 줄이 있어도 해당 버스에 바로 탈 수 있습니다. 이 자료를 ‘대기인원 0명’ 표본이나 전체 이용자의 평균 대기 0초로 입력하지 않습니다.

수용량과 비교할 때도 실제 정원 전체가 아니라 해당 승차 시점에 그 줄에 제공된 잔여 승차 가능 인원을 구분해야 합니다. FIFO·한 대 탑승이라는 조건 아래에서는 본인 앞사람과 본인이 그 범위에 든다는 관계를 검토할 수 있지만, 정확한 상한 인원을 이번 관측으로 정하지 않습니다. 본인 뒤의 새 유입이나 해당 분 전체의 최대 줄도 측정하지 않았습니다.

기존 모형의 20초 준비시간을 실제 경험에서 자동으로 더하거나 빼지 않습니다. 기존 44명·60명 값을 이번 차량의 새 실측 정원으로 기록하지도 않습니다.

[구조화한 관측 원문](boarding_admin_snu_1220_immediate.json)에 보고 사실과 사용자 지정 해석을 분리했습니다. 현재는 자료 접수만 했으며, 모형 비교·보정·실험·배포는 수행하지 않았습니다. 같은 탑승 경험을 개별 대기와 줄 존재의 독립된 두 표본으로 중복 집계하지 않습니다.
