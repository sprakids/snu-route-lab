## 저장소 보호

공개 상태의 쓰기 수치와 저장 바이트는 앱 자체 집계/추정이며 Cloudflare 계정 전체 사용량이 아니다. 부하 시험 역시 공급자 API를 호출하지 않는 합성 시험이다. 계정의 다른 프로젝트, 인덱스, 실제 차량 수에 따른 차이가 있으므로 무료 이용 보장을 뜻하지 않는다.

## 확인 자료

수집기 전체 시험은 27개 모두 통과했다. 승인 전환 시 누적 장부 유지, 중복 실행·재시작·한국시간 자정, 하루 호출 상한, 공개 조회의 쓰기 증가 방지, 셔틀 캐시와 저장소 보호를 포함한다.

노선당 차량 80대를 둔 하루 10,400건 합성 시험의 핵심 수집 쓰기 추정은 64,190행이었다. 보조 쓰기를 한도까지 채운 결과는 73,181행이며, 유지관리 여유 10,000행을 더해도 기존 85,000행 중단 기준 이내였다. 원본 30일·집계 365일의 데이터 크기 투영은 약 1.91GB였다. 이는 인덱스와 다른 프로젝트를 제외한 합성 시험 수치다.

- `before.json`, `after.json`, `receipt.json`: 설정 변경 전후 및 누적 장부 유지
- `public-verification.json`: 공개 사이트 반영과 이후 수집 확인
- `collector-tests.txt`: 수집기 회귀·저장 부하 시험 결과
- `configure.py`: 인증정보를 출력하지 않는 로컬 변경 도구. `--apply`는 이미 실행했으며 중복 적용을 거부한다.
