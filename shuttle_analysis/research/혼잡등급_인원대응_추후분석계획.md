# 혼잡등급과 실제 탑승 인원의 대응: 추후 분석 계획

작성·출처 확인일: 2026-11-09 KST  
상태: 분석 대상에 등록 / 현재 적용 인원 경계 미확인 / 인원 환산 미적용

사용자 요청에 따라, 실측 자료가 축적되었을 때 분석할 대상으로 **혼잡등급별 실제 차내 인원과 승차 가능한 잔여용량**을 추가합니다. 목적은 교외에서 교내로 들어올 때 이미 타고 있는 인원이 교내 하교 승객의 탑승 가능성에 미치는 영향을 추정하는 것입니다.

## 현재 확인한 내용

| 출처·시점 | 확인한 내용 | 이번 분석에서의 취급 |
| --- | --- | --- |
| 서울시 버스위치정보 API, 2026-11-09 열람 | `congetion`: 0 없음, 3 여유, 4 보통, 5 혼잡, 6 매우혼잡 | 코드·명칭의 근거. 확인한 페이지에는 현재 적용 인원 구간표가 없음 |

**현재 인원 구간을 공개한 자료가 어디에도 없다는 결론은 아닙니다.** 이번에 확인한 자료만으로 현재 관측 API의 각 코드에 대응하는 인원 범위를 확정하지 못했다는 뜻입니다. 수집 값 3·4·5·6은 사람 수가 아닙니다. 코드 0은 정보 없음으로 취급하며, 빈 버스 0명으로 바꾸지 않습니다.

## 자료가 쌓이면 확인할 항목과 이유

1. **현재 공식 기준표와 적용 이력**: 시행일, 차종 구분, BIT·위치 API·도착 API의 표현 차이를 조사합니다. 과거 수치를 현재 데이터에 잘못 적용하지 않기 위해서입니다.
2. **같은 차량·같은 시각의 실제 인원과 등급**: 직접 계수 또는 제공기관의 차량별 재차인원 등, 등급과 독립적으로 확인 가능한 인원 자료를 연결합니다. 등급 기록이 많아지는 것만으로 그 등급의 실제 인원을 알아낼 수는 없기 때문입니다. 교통카드 산출 재차인원도 누락·시각 지연이 있을 수 있어 직접 계수와 구분합니다.
3. **차종별 좌석·입석·등록 총정원**: 실제 운행 차량과 연결합니다. 현재 모형의 참고 정원과 차량별 확인 정원을 구분해야 실제 잔여용량을 계산할 수 있습니다.
4. **등급 갱신 시점과 승하차 전후 차이**: 제공 시각과 수집 시각, 정류장 도착·출발 상태를 구분합니다. 승차 전 인원과 승차 후 등급을 섞으면 정류장의 수요가 왜곡됩니다.
5. **교외 진입 부하와 정류장별 변화**: 같은 버스의 진입 전·후 및 교내 구간을 이어서 봅니다. 이때 총 재차인원을 다시 교내 모형 탑승객에 더해 중복 계산하지 않습니다.

## 필요한 대조 자료

| 묶음 | 최소 기록 |
| --- | --- |
| 차량·운행 연결 | 노선 ID, 차량 연결용 가명 ID, 운행 회차, 방향, 정류장 ID·순번, 위치·정차 상태 |
| 시간 | 제공기관 관측 시각, 수집 시각, 인원 계수 시각, 두 시각 차이 |
| 혼잡 신호 | 원래 혼잡 코드, 제공 여부, 만차 값과 값이 알려졌는지 여부 |
| 인원 대조 | 실제 또는 별도 산출 차내 인원, 자료 출처·계수 방법·오차, 승하차 전후 구분, 가능하면 승차·하차 인원 각각 |
| 차량 용량 | 실제 차종·차량 형식, 좌석 수, 입석·등록 총정원, 기준 출처·적용일 |

기존 위치·등급 기록은 보존합니다. 현재 자료에서 미제공인 관악02 등 노선의 혼잡도는 다른 노선으로 대체하지 않습니다. 추가 계수·기관 자료 확보는 후속 작업이며, 이 계획 등록으로 새 수집 일정이나 외부 연락을 실행하지 않았습니다.

## 분석 방법과 결과물

1. **시간을 맞춘 대조표 작성**: 같은 차량·운행·정류장 상태의 인원과 등급만 비교합니다. 반복 수집한 같은 제공기관 관측을 독립 표본으로 세지 않습니다.
2. **차종별 등급–인원 분포 추정**: 등급마다 인원 중앙값과 관측 범위·추정 구간을 산출하고, 등급 사이의 겹침과 갱신 지연을 확인합니다. 모든 버스에 보편적인 한 숫자를 억지로 지정하지 않습니다. 공식 경계만 확보한 경우에는 그 경계가 주는 범위와 별도 실측 검증 여부를 표시합니다.
3. **진입·하차 후 잔여용량 계산**: 같은 차량의 인원을 순서대로 연결해 `하차 후 재차 = 직전 재차 - 하차`, `승차 전 잔여용량 = max(0, 확인 정원 - 하차 후 재차)`를 계산합니다. 인원 범위와 하차의 불확실성도 결과에 전달합니다. 정원 초과 관측은 별도로 남깁니다. 회차 시 전원 하차는 확인 없이 가정하지 않습니다.
4. **수요 역추정의 한계 확인**: 정류장 전후 재차 차이는 `승차 - 하차`입니다. 등급 상승만으로 승차 인원이나 정류장 대기자 전체를 확정할 수 없습니다. 차외 대기, 탑승 실패, 경로 변경 자료가 확보되면 별도 대조합니다. 교외에서 탑승했다는 사실이 비학생이라는 뜻도 아닙니다.
5. **보정하지 않은 날짜에서 검증**: 기존 검토의 28일 분리 원칙(14일 보정·7일 선택·7일 최종검증)을 유지하되, 날짜 수만으로 적용을 결정하지 않습니다. 평일 하교·노선·방향·차종의 표본과 독립 인원 대조 자료가 필요합니다. 동일 날짜를 보정·검증에 중복 사용하지 않고 같은 차량·회차의 상관도 고려합니다.

후속 산출물은 현재 기준·시행일 출처표, 인원–등급 대조 자료, 차종별 등급→인원 구간표, 진입 부하·잔여용량 구간, 독립 검증 보고서입니다. **실제 인원 검증과 대기시간 검증은 별개**입니다. 대기시간 검증에는 대기 시작·실제 승차 시각과 타지 못한 회차·경로 전환 관측도 필요합니다. 모형이 만든 인원으로 등급 대응을 맞춘 뒤 이를 독립 실측 검증이라고 부르지 않습니다.
