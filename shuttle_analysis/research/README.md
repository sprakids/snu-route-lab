## 검증 실행

이 폴더에서 `Run-Checks.ps1`을 실행하면 됩니다. ZIP에는 `../input_handoff` 원본과 `../.deps`의 xlrd 2.0.2를 포함했습니다. Python 경로가 다르면 `-PythonExecutable`로 지정할 수 있습니다. PDF를 재생성하려면 reportlab이 있는 Python으로 `build_deliverables.py`를 실행합니다. PDF 생성에는 Windows 맑은 고딕 글꼴을 사용합니다.
