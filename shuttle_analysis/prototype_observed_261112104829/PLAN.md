# 실측 자료와 R모형의 구간시간 연결

2026-11-12. 사용자 요청에 따라 기존 구현 에이전트의 실측 분석과 협업한다.

- 원본 R10, 운영 V11, 수집기, 구현 에이전트의 분석 폴더에는 쓰지 않는다.
- 학습일은 2026-11-10, 날짜 분리 확인일은 2026-11-11로 고정한다. 기록기 중간 배포로 집계가 달라진 11/9는 신규 구간시간 추정에 사용하지 않는다.
- 인접 정류장 검출 사이의 경과시간만 사용한다. 이는 순수 주행시간이나 승하차 체류의 정답이 아니다. GPS/stopFlag/제공시각의 오차가 남는다.
- 노선·진행 순번·진입 시간별 학습 중앙값을 사용하되, 5개 미만의 학습 관측이면 기존값을 유지한다. 표본수는 독립 승객이나 독립 일수의 수가 아니다. 검출구간의 중복 상관이 남으므로 신뢰구간을 만들지 않는다.
- 교내40km/h 등 기존 물리 최소시간을 보존한다. 측정 검출시간이 그보다 짧더라도 물리 속도를 높이지 않는다.
- 기존 차량 출발시계·정원·통행 수요·목적지·행동 계수는 보존한다. 셔틀 배차간격, 교외 재차 인원, 등급별 인원을 추정해 채우지 않는다.
- 검증일 값은 학습이나 보정 셀 선택에 사용하지 않는다. 한 검증일의 개선은 다른 요일이나 대기열 정확도에 대한 입증이 아니다. 추가 모델 선택을 하면 그 날짜는 더 이상 최종 미사용 검증일이 아니다.
- 검출간 구간시간의 전체 평균절대오차가 기존보다 작을 때만 별도 R 후속 후보의 입력으로 연결한다. 이 결과만으로 공개 V11이나 경로 앱을 교체하지 않는다.
- 연결 후 수요·여석·FIFO·대기·전체 여정 결과는 별도로 검사한다. 20분 강제이탈·수요삭제·정원증가·변경횟수 제한은 금지한다.

다른 문제(미래 정보 분리, 반복 경로의 선택 일관성, 동시 대안 비교, 실제 승하차 처리)는 이번 입력 보정과 효과를 섞지 않고 후속 문제로 남긴다.


이번 후보의 실행 범위는 수요일 regular/peak 두 조건이다. 모든 평일을 통과했다고 주장하지 않는다.


검증 표현 정정: 11/11 자료는 구현 에이전트가 이미 기술적으로 살펴본 자료이다. 11/10 학습과 날짜를 분리한 사후 점검이며, 완전히 미사용인 최종 검증 자료로 주장하지 않는다. 학습값과 셀 선택에 11/11 값은 사용하지 않았다.
