# 국내 지도 API 무료 제공 범위 비교

확인일: 2026-11-04 KST. 공식 문서의 현재 무료 제공량을 비교했다. 사용자 계정별 무료 적용 여부나 실제 키 호출 성공까지 확인한 결과는 아니다. Google Maps 신규 데모 키 발급에는 아직 동의하지 않았고 새 키도 생성하지 않았다.

| 서비스 | 무료 제공량 | 적용 조건과 프로젝트 활용 |
|---|---|---|
| 카카오맵 | 지도 Web SDK 일 300,000건, 도보 경로 조회 일 1,000건 | 개발자 계정에서 처음 카카오맵 API를 활성화한 앱에만 무료 쿼터. 전체 API 월 3,000,000건 제한도 함께 확인해야 함. 지도 표시와 도보 경로를 같은 제공기관에서 연결할 수 있음 |
| 네이버 클라우드 Maps | Dynamic Map 월 6,000,000건 | 대표 계정 1개에 무료 적용. 기존 AI NAVER API 내 지도 상품과 신규 Maps 상품을 구분해야 함 |
| TMAP | 지도보기 일 100,000건, 경로안내 일 1,000건 | 경로안내에 자동차·보행자 안내 포함. 무료체험의 API별 제한과 이용 조건 적용 |

## 권장 방향

이번 서울대 지도는 **카카오맵을 먼저 검토하는 것이 적합하다**고 판단한다. 근거는 공식 문서에 지도 표시뿐 아니라 도보 경로 조회가 포함돼 있고, 무료 적용 앱이라면 배경지도와 정류소까지의 보행 경로를 같은 제공기관으로 시험할 수 있기 때문이다. 서울시 버스 GPS·혼잡도와 학교 셔틀 자료는 별도 데이터로 지도 위에 표시하며, 자체 통합 경로 계산이 필요하다.

이 추천은 관악캠퍼스의 모든 계단·건물 출입구·보행로가 정확히 반영됐다는 검증 결과가 아니다. 실제 노선과 캠퍼스 출입구를 정해 보행 경로 응답을 대조해야 한다. 등록·키 생성·지도 로딩은 아직 수행하지 않았다.

## 조건 확인

- 카카오의 무료 쿼터 적용 방식은 2026-07-21부터 변경됐다. 신규 앱을 무작정 생성하기 전에 기존 앱의 ‘카카오맵 무료 쿼터’ 배지를 확인해야 한다. 두 번째 활성화 앱부터 또는 무료 쿼터를 초과해 사용할 때는 비즈월렛 연결과 유료 API 사용 설정이 필요하다고 문서에 안내돼 있다.
- 카카오의 일간 지도 한도와 월간 전체 API 한도는 서로 다른 제한이다. 일간 수치에 월의 일수를 곱해 무료 보장량으로 설명하지 않는다.
- 네이버의 기존 AI NAVER API 내 지도 API는 2025-07-01부터 무료 이용량이 종료됐다. 무료 제공량은 신규 Maps 상품과 대표 계정 여부를 기준으로 확인한다.
- TMAP 공식 약관은 API로 얻은 데이터를 저장 후 24시간 이상 사용할 수 없다고 안내한다. 보행 경로를 장기 사전 계산·저장하려면 이 조건을 검토해야 한다. 이는 서울시에서 별도로 받은 버스 원자료와 구분되는 조건이다.

- [네이버 상품 변경 공지](https://www.ncloud.com/support/notice/all/1965?page=2): AI NAVER API와 Maps의 무료 이용량 적용 구분.
