# 제2공학관 19~20시 승차 출발지 조사

제2공학관 정류장 **21275(120000173)**에서 버스에 실제로 타는 사람의 직전 건물과 그날 마지막 수업 종료시각을 확인한다. 반대편 제2공학관 정류장은 별도 지점이다. 아래는 현장 사용을 위해 작성한 양식이다.

## 승객에게 물을 세 가지

“서울대 하교 교통 연구를 하고 있습니다. 이름 없이 세 가지만 여쭤봐도 될까요?”

1. **이 정류장으로 오기 직전에 어느 건물이나 장소에서 출발하셨고, 몇 시쯤 나왔나요?** 건물 번호나 이름으로 기록한다. 다른 정류장·학교 밖·모름도 허용한다.
2. **오늘 마지막으로 실제 수업이 끝난 시각과 건물은 어디인가요?** 오늘 수업 없음·기억 안 남·해당 없음도 각각 기록한다. 시간표상 종료와 다른 경우 실제 종료를 기록한다.
3. **그 수업이 끝난 뒤, 또는 오늘 수업이 없었다면 버스 타러 오기 직전에 주로 무엇을 하셨나요?** 바로 이동 / 자습·과제 / 연구·실험·근무 / 식사·모임 / 교내 환승 / 기타 / 응답 생략. 학생의 하교 비중을 따로 계산할 경우 소속 구분(학부생·대학원생·교직원·기타·생략)과 이번 통행 목적(귀가·다른 목적·생략)을 함께 받는다.

## 기록 방법

* 일반 학기 목요일 두 날 이상 19:00~19:59에 시행한다. 19시 전부터 서 있던 승객도 해당 시간에 타면 포함하고, 20시 이후 탄 사람은 분리한다.
* 한 사람은 출발하는 **모든 차량의 노선·실제 승차시각·전체 승차 인원**을 기록한다. 다른 사람은 문이 열리기 전 대기 중인 사람에게 짧게 물은 뒤 실제 승차를 확인한다. 갑자기 온 차량에 바로 탄 사람은 총계와 접촉 누락에 남긴다. 대기줄 길이만으로 승차 인원을 대신하지 않는다.
* 한 번에 여럿이 올 때에는 사전에 정한 간격(예: 무작위 첫 순번 뒤 매 세 번째)으로 접근한다. 임의로 답해 줄 만한 사람을 고르지 않는다. 노선·15분 구간별 접촉·거절·완료·바로 승차해 접촉하지 못한 인원도 남긴다. 연락처·카드번호·학번은 수집하지 않는다.

| 날짜·15분 구간 | 승차 노선·시각 | 출발 건물·퇴실 시각 | 마지막 수업 건물·실제 종료 | 직전 활동 | 소속·귀가 여부(선택) | 응답 상태 |
|---|---|---|---|---|---|---|
| | | | | | | |

같은 날짜·시각·노선별로 실승차 분모와 응답 수를 함께 공개한다. 응답이 충분한 구간은 그 구간의 실승차 수에 응답 비율을 곱해 합산할 수 있다. 응답 없는 구간과 대규모 접촉 누락은 미확인으로 표시한다. 이렇게 해야 ‘302동 수업 뒤 남아 있던 사람’, ‘다른 건물 수업 뒤 302동에서 활동한 사람’, ‘당일 수업 없이 연구·근무하다 떠난 사람’을 나눌 수 있다.
