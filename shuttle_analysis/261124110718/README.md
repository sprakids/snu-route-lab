# 수요모델의 경사별 체감 보행거리

로컬 연구 모델 **R261124110718**은 학생이 정류장을 고르거나 걸어서 귀가할지 판단할 때 도보 경사에 따라 체감거리를 다르게 계산한다. 비교 기준은 같은 통행 수요·운행계획을 사용한 R261124103744다. 기존 실험실 주소에서 새 모델이 열린다. [수요모델 지도](http://127.0.0.1:8794/) · [이전 모델](http://127.0.0.1:8794/?model=R261124103744) · [평일·배차별 비교 결과](comparison.json)

| 보행 방향의 경사율 | 실제 보행거리 100m를 걸을 때 체감거리 |
|---|---:|
| −20% 이하 | 50m |
| −10% | 75m |
| 평지 | 100m |
| +5% | 150m |
| +10% | 200m |
| +20% 이상 | 300m |

사용자가 정한 기준점은 +10%에서 2배, −10%에서 0.75배다. 그 사이 구간은 평지 1배를 잇는 직선으로 계산했다. 가파른 계단이나 지형 고도 오차로 체감거리가 과도하게 변하는 것을 줄이기 위해 −20% 이하와 +20% 이상은 각각 0.5배·3배로 제한했다. 배수는 수요 실험용 가정이다.

**같은 길을 반대로 걷는 예시**로 경영대와 정문을 잇는 경로 2489를 계산했다. 실제 경사면 길이는 양방향 233.94m다. 경영대에서 정문으로 내려갈 때 체감거리는 175.60m이고, 같은 좌표열을 거슬러 올라갈 때는 467.29m다. 제2공학관→학부생활관처럼 오르막과 내리막이 섞인 길에서는 출발점이 더 높아도 오르막 부담의 합이 내리막 할인보다 클 수 있다.

### 거리와 시각을 계산하는 방법

1. 기존 모형의 4,616개 보행 경로에서 길을 최대 25m 단위로 나눈다. 각 구간에서 이동 방향의 높이 변화량을 수평거리로 나누어 경사율을 구한다. 전체 경로의 처음과 끝이 같은 고도여도 중간에 언덕이 있다면 이 방식으로 반영할 수 있다.
2. 각 구간의 **실제 경사면 길이 × 해당 경사 배수**를 합산한다. 동일한 길을 반대로 걸으면 실제 길이는 같고 체감거리는 다르다. 실제 보행 초는 이전 R의 경사면 거리와 개인별 속도를 쓴다. 버스를 탈 수 있는 시각과 하차 후의 환승 가능성은 이 실제 시계로 판단한다.
3. 기숙사·대학동의 최초 도보 전환에는 기존 거리별 선호함수와 개인별 난수를 그대로 쓰고, 함수에 넣는 길이를 체감거리로 바꾼다. 기존 윗공대 기숙사행의 평균 내리막 할인은 새 구간별 계산으로 교체했다.
4. 같은 강의동·출발점·목적지·30분대에서 이미 가능했던 초기 경로들에는 기존 선택 비중을 기준으로 경사로 인한 체감거리 증감 1km당 로그 선호가 1만큼 바뀌도록 했다. 이 값은 기존 대학동 거리선택 식의 척도를 재사용한 실험 가정이다. 체감 차이가 동일하면 기존 선택을 유지한다. 각 학생의 출발시각과 보행속도로 시간표를 따라 끝까지 이어지는 대안을 확인한다. 기숙사·대학동의 직접도보 여부는 3단계에서 정하고, 여기에서는 같은 수단 집단의 정류장·노선만 다시 비교한다.
5. 정류장에서 계속 기다릴지, 다른 정류장이나 목적지로 걸을지 다시 판단할 때에는 남은 도보 구간의 **체감시간과 실제 보행시간의 차이**만 선택 비용에 더한다. 실제 차량 위치, 탑승 시각, 도보 완료 시각은 물리적인 시계로 진행한다.

### 검증과 실행

같은 평일 5일 기본 배차의 가중 통행 합계는 78,169건 상당이다. 처음부터 전 구간을 걸으려던 비율은 기존 20.2%에서 17.6%로, 정류장에서 선택을 바꾼 경우까지 포함해 차량 없이 도착한 비율은 23.8%에서 21.6%로 변했다. 윗공대 세 건물 출발 기숙사행 1,937.6건 상당 중 차량 없이 도착한 비율은 40.9%에서 1.1%로 낮아졌다. 이 집단은 이전 모형에서 경로 전체의 평균 내리막에 할인을 받았고, 새 모형에서는 중간 오르막의 부담까지 반영된다. 이 큰 차이가 새로운 관측으로 확인된 학생 행동을 뜻하지는 않는다.

동일한 평일 5일과 배차 2종의 10개 원장에서 차량 정원 위반·미완료 통행·한 정류장 20분 초과 연속 대기 가중치는 모두 0이었다. 한 정류장의 최장 연속 대기는 20.0분이었다. 길찾기 앱의 별도 테스트 36개와 경사 선택 계산의 회귀 테스트 3개도 통과했다.

비교 표의 단위는 수강인원으로 가중한 모의 통행이다. 월~금 기준·피크 배차에서 각 학생의 출발시각과 가중치, 목적지 인원, 수송 공급, 대기열·차량 정원, 실제 경로와 시간을 검증한다. 모형상 선택률의 변화와 학생 선호에 대한 실측 검증은 별개다. 지형 높이와 실제 계단·고가 보행로의 높이 사이에는 차이가 날 수 있다. [이전 R의 고도 자료와 검산](../261124103744/campus-survey/README.md) · [지도 원장의 보행 경로](../261124103744/README.md)
