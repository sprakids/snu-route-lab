# 서울대 하교길 API 운영계정 신청안

서비스명: 하교길 · SNU Route Lab
공개 URL: https://snu-route-lab.vercel.app
대상: 서울특별시_버스위치정보조회 서비스
사용 기능: getBusPosByRtid (포털 명세명 getBusPosByRtidList)
신청 트래픽: 10,000회/일

## 활용사례 소개

서울대학교 관악캠퍼스에서 서울대입구역·낙성대역으로 이동하는 경로를 비교하는 무료 수업·연구용 웹 시제품입니다. 서울시의 5511·5513·5516·관악02-1·관악02-2 버스 위치·혼잡 정보와 공식 노선 경로를 이용하고, 학교 셔틀 시간표·운영사 노선도 관측·보행망을 결합합니다. 사용자에게 도보·대기·차내시간과 버스 도착예정을 구분하여 보여 줍니다. 관측값과 과거 기록·시간표에 따른 추정을 표시하며, 실제 정확도와 대기열 검증은 수집 중입니다.

## 증량 사유

하교 수요가 집중되는 평일 15~19시에 5개 노선을 각각 15초 간격으로 조회하려면 4,800회가 필요합니다. 나머지 11:20~15:00, 19:00~23:10에는 120초 간격으로 1,175회, 마지막 조회 5회, 오류·긴급 재조회 520회를 포함해 앱 자체 상한을 6,500회로 관리합니다. 방문자 수와 독립적인 공용 수집기로 호출하고 오류도 요청 전에 차감합니다. 기본 1,000회 한도로는 위 하교 시간 집중 관측을 수행할 수 없어 10,000회/일을 신청합니다. 신청 한도를 모두 소진하도록 운영하지 않습니다.

## 무료 저장소 보호

회차별 압축 원본과 노선별 묶음 통계로 저장합니다. 상태 조회는 DB 쓰기를 하지 않습니다. 정기 5,980회와 예비 520회의 가상 실행 검증을 마쳤으며, 이 앱의 SQL 커서 사용량과 요청 추정치에 따라 갱신을 줄이고 원본은 30일·집계는 1년 보관합니다. 계정의 다른 프로젝트 사용량까지 포함한 무료 한도 보장은 아닙니다. 인증키와 사용자의 GPS를 공개 기록에 저장하지 않습니다.

신청 상태: 활용사례·서비스 화면·대표 이미지를 포함한 통합 양식을 제출했습니다. 사용자가 보안문자와 마지막 제출을 완료한 뒤 SNU 프로필의 승인 상세 화면을 확인했습니다. 서울특별시_버스위치정보조회 서비스의 운영계정 상태는 '승인'이며, getBusPosByRtidList의 승인된 일일 트래픽은 10,000회입니다. 활용기간은 2026-11-07~2028-11-07입니다. 활용사례가 별도 공개 목록에 게시됐는지는 확인하지 않았습니다.

배포 상태: 공개 앱 v0.6.1과 묶음 저장 수집기를 배포했습니다. 실제 승인을 확인한 뒤 provider_approved_limit=10000 설정을 영구 저장하고 수집기를 활성화했습니다. 평일 정기 5,980회+예비 520회=최대 6,500회, 주말 정기 1,780회+예비 220회=최대 2,000회입니다. 수집시간은 11:20~23:10 KST이고, 평일 15~19시 노선별 15초, 그 외 120초 간격입니다. 동일 원본 시각 반복·저장소 보호 조건에서는 갱신을 완화합니다.

적용 후 실제 확인: 오늘 사용량이 61회에서 66회로 늘었고, 5개 노선의 같은 회차 관측이 모두 오류 없이 저장됐습니다. 공개 앱 /api/status에도 승인 한도 10,000회와 주말 상한 2,000회가 반영됐습니다. 시간 지정 계산은 historical_and_timetable 모드, latest_positions_used=false이며 행정관 셔틀 후보에 timetable_plus_conditional_queue_scenario 대기모형이 포함됐습니다. 활성화 증거는 app/runtime/operating_policy_activation_2026-11-07.json, 공개 경로 응답은 app/runtime/v061-public-plan.json에 보관합니다.

남은 사용자 설정: 업로드에 사용한 크롬 확장의 '파일 URL에 대한 액세스 허용'은 사용자가 다시 꺼야 합니다. 도구의 주소 정책상 이 설정의 자동 복원은 수행하지 못했습니다.
