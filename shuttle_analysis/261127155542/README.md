## 같은 종료시각에서 실제로 달라진 모의 출발

편람상 18시까지 끝나는 목요일 윗공대 하교 통행은 1,914.49건 상당이었다. 모든 통행에 비교할 다른 권역의 동일 종료 분 수업이 있었다. 각각의 종료 분에서 두 권역의 평균을 구한 뒤 윗공대 통행의 시간대 비중으로 표준화했다. V12에서 윗공대는 다른 권역보다 평균 0.80분 먼저 건물을 나갔다. 출발 확률과 체류 규칙이 공통이어도 수업별 조기 종료, 학생별 퇴실·체류 표본이 달라 소폭 차이가 생긴다.

기본 R120은 기존 체류 대상 467.58건 상당에게만 추가 체류시간의 상한을 90분에서 120분으로 늘렸다. 같은 난수와 같은 학생끼리 대조하니 대상 집단의 출발은 평균 14.25분, 윗공대 전체는 평균 3.48분 늦어졌다. 동일 종료 분의 다른 권역과 비교한 차이는 −0.80분에서 **+2.68분**으로 바뀌었다. 반대로 60분 상한을 둔 R60에서는 −4.28분이었다. 이는 설정한 행동이 모의 건물 출발에 반영됐는지 확인하는 값이다.

## 실제 승차와 비교하는 방법

제2공학관에서 탄 뒤 교외 정류장에서 내린 승차 건수를 같은 날짜·정류장 ID·시각에 맞췄다. 정류장에 온 시각·줄의 길이·최종 귀가시각은 이 카드 집계에서 확인할 수 없다. 기준 배차와 피크 배차는 같은 목요일의 대안 운행계획이다. 수업 출발지·승차지는 서로 다른 위치이므로 모의 승차 원장에서는 출발 건물과 기존 체류 대상 여부도 따로 추적했다. [시간별 승차 원표](목요일_정류장별_승차.csv) · [권역·체류 대상별 검산](제2공학관_출발집단별_검산.csv)
