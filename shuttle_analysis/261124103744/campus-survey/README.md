# 관악캠퍼스 보행망의 최대 고도차

**강의동과 생활관 주변에서는 정문 부근에서 제2공학관 옆까지 약 184m 올라갈 수 있다. 같은 길을 내려오면 약 184m 낮아진다.** 서울시가 학교시설로 지정한 산지까지 포함하면 정문 부근과 관악산 정상 표지점 인근 보행로 사이의 고도차가 약 555m까지 커진다. 표의 값은 지형 자료로 계산한 추정치다. [두 범위를 비교한 지도](캠퍼스_고도차.png)

| 지표 | 교육·생활권의 일상 보행망 | 서울시 학교시설 안 보행망 · 등산로 포함 |
|---|---:|---:|
| 검색한 길의 총길이 | 40.73km | 63.13km |
| 지도상 최저 → 최고 지점의 지형고도 | 60.9 → 245.2m | 60.5 → 615.4m |
| 연결된 두 지점의 최대 순상승 / 순하강 | +184.3 / −184.3m | +554.9 / −554.9m |
| 위 두 지점을 잇는 최단 보행거리 | 2.79km | 3.25km |
| 최단경로들 중 최대 누적 상승 / 하강 | 234.1 / 234.1m | 654.9 / 654.9m |
| 최대 100m 평균 오르막 / 내리막 | +44.0 / −44.0% | +56.0 / −56.0% |

### 어디에서 나타났나

- **교육·생활권**의 최저점은 정문 부근(37.465682, 126.948459), 최고점은 제2공학관 건물 외곽 약 5m 옆(37.448148, 126.952746)이다. 제1공학관 인근 계단과 보행로에서는 수평 보행거리 100m 동안 지형이 약 44m 높아졌다. 이 최급경사 구간과 정문에서 출발하는 최대 고도차 경로는 서로 다른 길이다. [계단 구간](https://www.openstreetmap.org/way/481915895) · [이어지는 보행로](https://www.openstreetmap.org/way/481915893)
- **학교시설 전체**의 최저점은 정문 부근(37.465739, 126.948296), 최고점은 지도상 관악산 정상 표지점에서 약 31m 떨어진 등산로(37.444880, 126.964114)다. 자운암능선에서는 수평 보행거리 100m 동안 지형이 약 56m 높아졌다. [자운암능선](https://www.openstreetmap.org/way/356701922)
- 생활권에서 약 2.79km인 정문 부근→제2공학관 옆 최단경로는 오르막 합이 224.8m, 중간 내리막 합이 40.5m다. 둘을 빼면 양 끝의 순고도차 184.3m와 일치한다. 생활권 전체에서 누적 상승이 최대인 경로는 다른 두 끝점을 잇는 약 3.03km 경로다. 임의의 왕복을 허용하면 누적 상승·하강을 계속 키울 수 있으므로 표의 누적값은 각 출발지와 도착지 사이의 **보행거리 최단경로**끼리 비교했다. [양방향 극값 경로 GeoJSON](extremes.geojson) · [두 끝점·좌표·도로 번호](result.json)

### 경계와 자료 범위

서울특별시 도시계획시설(공공·문화체육시설) 2026년 9월 자료에서 이름이 ‘서울대학교’인 유일한 도형을 추출했다. 식별자는 `11000UQ155PS202402010001`, 원본 좌표계는 EPSG:5174이며 면적은 3,929,174㎡다. 서울대학교가 소개한 관악캠퍼스 부지 약 4,109,000㎡와 집계 기준이 다르다. 학교시설 경계 안에 있는 등산로는 포함하고, 경계 밖으로 나갔다 돌아오는 지름길은 제외했다. 대학 소유 모든 필지나 경계 안 모든 지표면의 최고점까지 조사한 수치는 아니다. [서울시 2026년 9월 공간자료](https://data.seoul.go.kr/dataList/OA-20961/F/1/datasetView.do) · [서울대학교 공식 캠퍼스 면적](https://snu.ac.kr/brochure/ko/information/) · [분석에 사용한 학교시설 경계](seoul-school-boundary.geojson)

생활권은 이 경계와 OpenStreetMap의 ‘서울대학교 관악캠퍼스’ 영역이 겹치는 1.345㎢로 정의했다. 이 안에서 등산 난도·등산로 가시성 표지가 있는 길, 임도, 포장 여부를 확인할 수 없는 일반 산길을 제외했다. 정문·강의동·생활관을 오가는 분석을 위한 지리적 선택이다. 월담·시가지·산길을 가로질러 서로 다른 길을 연결하지 않았다. 보행자가 실제로 들어갈 수 있는지, 교량·지하차도 높이, 계단 단높이는 현장에서 확인할 사항이다. [OSM 생활권 경계](https://www.openstreetmap.org/relation/11917142) · [OSM 원자료 저작자표시](https://www.openstreetmap.org/copyright)

### 계산과 검산

1. **보행 가능성**을 먼저 정했다. 2026년 11월 24일 OSM 지도 API에서 서울시 도형 전체를 포함하는 사각형을 내려받았다. 실외 보행로·계단·보행 허용 도로를 추리고 사유지·보행 금지 등 명시적 제한을 적용했다. 경계를 가로지르는 선은 실제 교점에서 잘랐다. OSM에서 같은 노드를 공유하는 길만 연결하므로 지도에서 겹쳐 보이는 고가·하부 도로는 자동으로 환승점이 되지 않는다. 학교시설망은 742개 OSM way, 32개 연결 성분, 생활권은 659개 way, 29개 성분이다.
2. **보행로 고도**는 길을 최대 5m마다 나눈 뒤 Mapzen Terrarium z14 지형 타일의 픽셀 중심을 기준으로 이중선형 보간했다. 5m는 계산 지점 간격이다. 타일을 세분해도 실제 지형 측량의 정밀도는 높아지지 않는다. 교량 상판, 사면 옆 건물에 붙은 계단 등에서 실제 발밑 경사와 차이가 날 수 있다. [Mapzen / AWS 지형 자료](https://registry.opendata.aws/terrain-tiles/)
3. **순고도차**는 갈 수 있는 방향을 따라 두 끝점의 고도를 뺐다. **누적 상승**은 경로 전체에서 양의 고도 변화만 더했다. 누적 하강은 음의 변화의 크기를 더했다. 생활권 72,003,644쌍, 등산로 포함 191,959,728쌍의 도달 가능한 방향별 표본 쌍에 최단거리 기준을 적용했다. 최장 누적 상승·하강 경로는 별도의 최단거리 계산과 다시 대조했다.
4. **100m 경사**는 지도상의 직선거리 대신 보행망 최단거리 100m를 사용했다. 각 표본에서 교차로를 넘어 탐색하고 마지막 간선에서 정확히 100m가 되는 지점을 계산했다. 다른 쪽에서 접근해 더 짧아지는 구간은 제외했다. 경사율은 고도 변화 ÷ 수평 보행거리 × 100이다. 양방향 통행이 가능한 구간은 역방향도 평가했다. 대표 구간의 길이·경계 포함 여부와 더 촘촘한 2.5m 표본의 결과를 별도로 검산했다. [검산 결과](verification.json)

### 재현

Python 3.12, Pillow, Shapely 2.2 이상, pyproj, pyshp, NetworkX와 Node.js 환경에서 아래 순서로 실행한다. OSM 스냅샷, 서울시 원본 ZIP, 지형 타일 SHA-256은 결과 JSON에 있다. 이 계산은 R 엔진의 배차나 학생 이동을 재실행하지 않는다.

```powershell
python survey.py
python verify_survey.py
python draw.py
```

서울시 파일은 자료 페이지의 2026년 9월 ZIP(서비스 OA-20961, 파일 순번 6)이다. 사용한 OSM 질의는 [캠퍼스 전역 지도 API](https://api.openstreetmap.org/api/0.6/map.json?bbox=126.9465,37.4430,126.9711,37.4700)에서 확인할 수 있다. 최신 OSM 응답은 보관한 스냅샷과 달라질 수 있다.
