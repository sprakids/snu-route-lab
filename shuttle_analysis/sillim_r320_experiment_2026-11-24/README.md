# 신림선 관악산역을 이용하는 하교생 320명 실험

목요일 기본 배차에서 기존 지하철역행 수요 320명분의 접근 목적지를 관악산역으로 옮겼다. 모의 하교생은 건물에서 출발해 평균 **16.9분** 만에 역 마커에 닿았다. 캠퍼스에서 학생이 기다린 시간을 모든 정류장에 걸쳐 합산하면 오후 3~7시에 **3,472인·분(5.21%)** 줄었다. 기숙사삼거리의 교내 순환 셔틀처럼 대기가 늘어난 곳도 있었다.

## 320명의 근거와 범위

2026년 11월 5일 목요일 15~19시 관악산역 승차 기록은 1,295건이다. 그중 교내 정류장에서 탄 시내버스에서 직접 갈아탄 기록이 87건이다. 별도 집단인 125건은 오전 교내 하차 이후 다음 유료 통행이 오후 관악산역에서 시작된 기록이다. 학생 비율을 80%, 이 두 번째 집단의 오전 단서 포착률을 40%로 가정하면 예상 하교 통행은 0.8 × (87 + 125 / 0.40) = 319.6건이다. 학생 여부와 통행 목적을 식별할 수 없어 카드 자료만으로 확정할 수 있는 범위는 0~1,295건이다. [카드 집계와 산식](../sillim_ridership_2026-11-24/scenario_320.json)

| 실험 조건 | 관악산역을 통한 하교 인원 | 민감도 분석에서 부여한 확률 |
|---|---:|---:|
| 낮은 수요 | 240명 | 25% |
| 기준 수요 | 320명 | 50% |
| 높은 수요 | 400명 | 25% |

세 확률은 시나리오에 부여한 가중치다. 이번에는 사용자가 선택한 가운데 조건을 한 번 실행했다. 아래 인원은 가중 모의 통행을 사람 수로 환산한 값이다.

## 출발지와 역 접근 경로

대조군은 대학동·기숙사 도보 선택을 보정한 R261124101820의 목요일 기본 배차다. 실험군 R261124101959에서는 서울대입구역행 213.8명과 낙성대역행 106.2명 상당을 67개 출발 건물에 걸쳐 관악산역으로 재배정했다. 실제 최종 귀가지를 알 수 없어 두 기존 지하철역행 집단을 대체 가능한 수요로 가정했다. 각 수업에서 발생한 수요와 건물별 출발 시각, 대학동·기숙사 목적 수요, 차량 공급은 양측이 같다. [대조군 실행 기록](../261124101820/runs/regular-thu/attempt-01/result.json)

시내버스 연계 몫은 87건의 80%인 69.6명으로 배정했다. 나머지 250.4명은 건물에서 역까지 걷거나, 교내 순환·역순환 셔틀로 이동한 뒤 걷는 후보 중 시간표상 빠른 쪽으로 배정했다. 시내버스는 교내 핵심 정류장에서 승차하는 경로만 허용했다. 양쪽 모두 방향·승하차 가능 여부와 보행망을 확인하고, 차량 한 대로 접근하는 후보를 비교했다. 승차 대기 중에는 모형의 만차·대기 규칙에 따라 역까지 걷기로 변경할 수 있다. [경로 선택과 보행망 처리](experiment.py)

차량 미탑승 집단의 대기에는 정류장에서 기다리다가 도보로 바꾼 시간이 들어간다. 전체 역 접근시간의 중앙값은 16.41분, 90백분위는 21.37분이었다. 수단별 평균은 출발 건물과 출발 시각이 다른 집단에서 나왔다. [집단별 통행 원장](station_trips.csv)

가중치 320명 모두 15:03~18:46에 역 마커(37.468964, 126.945242)에 닿았다. 마커와 연결한 보행망 노드 사이 거리는 약 6.8m이다. 건물·정류장 끝점 연결에는 최장 110m까지 허용했고, 보행로에서는 평지 4.8km/h와 계단 0.7m/s에 기존 개인별 보행 배율을 적용했다. 정확한 출입구와 개찰구까지의 동선은 실측이 필요하다. 마커에서 개찰까지 일괄 2분 또는 4분을 더해도 이번 표본의 15~19시 합계는 320명이었으며 일부 시간대의 값은 바뀌었다. 시간대별 목표를 건물 출발 집단 선택에 사용했으므로 실측 적합도는 다른 날짜에서 평가해야 한다. 전체 정류장 합계는 **66,591.5 → 63,119.2인·분**이었다. 차이를 240분으로 나누면 동시에 대기하는 인원이 전체 정류장 합산 평균 14.5명 줄었다. 다른 학생의 탑승·대기·경로 변경까지 반영한 결과다. 최종 귀가지, 실제 수단 선호, 교외 승객의 재차인원과 도로 지체를 실제와 다르게 가정하면 효과가 달라진다. [정류장별 합계](stops.csv) · [정류장별 시간대 집계](stop_hours.csv)

## 검산과 재현

두 실행 모두 하루 통행 16,517명 상당이 완료됐다. 원 출발집단 63,120개 각각에서 건물·출발 시각·가중치 보존을 대조했다. 차량의 정류장 사건 22,701개의 시각과 정원이 일치했고, 승차 순서 경합 364건을 확인했다. 정원 초과는 0건이었다. 시간대 목표의 경계에서 분할한 8개 집단도 원래 수업 ID로 되돌려 종료 시각을 검산했다. [독립 검산 결과](run/independent_checks.json) · [비교 수치와 입력 파일 지문](comparison.json)

실험 입력은 [experiment.py](experiment.py)에 있고, [verify_saved.py](verify_saved.py)와 [compare.py](compare.py)는 저장된 원장만 읽어 재검산한다. 최초 실행 뒤 기존 검산기가 분할 ID의 수업 시각을 찾는 단계에서 멈춰, 원래 수업 ID 연결을 반영한 검산기로 같은 원장을 다시 확인했다. 최초 실행 소스는 [보관본](run/launched_experiment.py)에 있다.
