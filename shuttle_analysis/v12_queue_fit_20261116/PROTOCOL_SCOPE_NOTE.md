# 정적 검토 후 범위 명확화

수치 결과를 해석하기 전에 구현 검토의 한계를 명시합니다. 설정·실행 코드는 바꾸지 않았습니다.

- 초기 빈줄 기본 대기의 초 단위 위상만 기댓값으로 바꿉니다. 현재 FIFO/정원 추가 지연, 후속 환승 가능 여부, 동점 ETA, 지역 시간대 간격 표본과 빈 표본의 기존 점수 fallback에는 정해진 운행 시각이 남습니다. 전체 행동이 모든 위상에 불변하거나 미래 시각을 전혀 안 쓰는 것으로 해석하지 않습니다.
- 기존2분은 Gumbel 판단 오차의 척도입니다. 오차가 ±2분으로 제한된다는 뜻은 아닙니다. 기댓값이 있는 후보가 적어도 하나 있을 때 동일 물리 노드의 대표 하나를 확률 선택에 넣습니다.
- 기존 flexible 플래그를 false로 다시 쓴 오류가 아니라, true 상태에서도 낮은 현재 예상 대기 때문에 대안 검토 자격을 닫는 제약을 고친 것입니다. 최초 선호의 해제 조건과 해제 후의 검토 자격을 구분합니다. 한 번 풀린 이후 셔틀을 다시 이용하는 사람에게도 매번 초기 충성 조건을 다시 요구하지 않습니다.
- 기존 early_shuttle 집계는 현재 수단이 셔틀인 모든 변경을 초기 충성 해제로 취급합니다. 새 모델에서는 이미 허용 상태가 풀린 뒤의 변경을 구분해야 합니다. 원장에는 최초 허용 해제 시각이 별도로 없어 모든 과거 허용 계기를 복원할 수는 없습니다. 최초 해제의 코드 경계와 별도 동작 검사를 검증하고, 한계 전 셔틀 이탈은 허용 상태 필드와 함께 따로 노출합니다. 이를 전부 위반이나0건으로 표시하지 않습니다.
- 새 승차 원장에는 계획상 마지막 단계 여부가 있으므로5516 최종 방향 검사는 모든 실제 승차에서 이 필드를 직접 검사합니다. 중간승차 후 나중에 도보로 바꾸는 선택은 제외하지 않습니다.
- 초과 원장은20분 기준과 개인 P 기준을 독립 집계합니다. P<20분인 사람의 P 초과도 포함합니다. 기존 표에 없던 노출이 추가되어 수치가 커지는 경우를 모델 악화와 혼동하지 않습니다.

배차 평균 대기 관계의 외부 근거는 [van Oort(2016),2.2~2.3절](https://link.springer.com/article/10.1007/s12469-016-0121-3)입니다. 이 논문은 고빈도·무작위 도착 조건을 다루며 서울대의 개인 기다림 분포,2분 오차,기숙사 행동이나 모든 낮은 빈도 노선의 도착 패턴을 측정한 자료가 아닙니다. 여기서 주어진 시간표의 간격으로 계산한 빈줄 참고값을 개인의 실제 만차 대기와 동일시하지 않습니다.
